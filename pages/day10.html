The 'Why' — Conceptual Breakdown

The Wall-of-Text Problem

iwconfig wlan0 prints something like: wlan0 IEEE 802.11 ESSID:"CorpWifi-5G" ... Signal level=-58 dBm ... Extracting the SSID and signal with string splits is fragile — the format changes between Linux kernel versions, and any extra space breaks your split index. Regular expressions solve this by describing the pattern you're looking for, not the exact position.

Named capture groups make regex self-documenting.
Instead of match.group(1) (what's group 1 again?), you write match.group("ssid"). Your code reads like documentation — and 6 months later, you still know exactly what each group captures.

re.search() vs. re.match() vs. re.findall()

re.match() only matches at the start of the string — almost never what you want for multi-line command output. re.search() scans through the entire string and finds the first match — the right choice for extracting fields from a block of text. re.findall() returns all non-overlapping matches — useful for extracting a list of all BSSIDs or all channel numbers from a scan dump.

Block 1 — Regex Fundamentals with Named Groups

Named groups use the syntax (?P<name>pattern). After a match, you access the captured text with match.group("name"). This is infinitely more readable than positional group numbers.

Python Day10_regex_parser.py 
# =============================================================
# Day 10: Parsing iwconfig/netsh with Python regex
# =============================================================

import re
import subprocess
import platform

# Sample iwconfig output (what you'd see on Linux)
IWCONFIG_SAMPLE = """
wlan0     IEEE 802.11  ESSID:"CorpWifi-5G"
          Mode:Managed  Frequency:5.18 GHz  Access Point: AA:BB:CC:01:02:03
          Bit Rate=300 Mb/s   Tx-Power=20 dBm
          Retry short limit:7   RTS thr:off   Fragment thr:off
          Encryption key:off
          Power Management:on
          Link Quality=52/70  Signal level=-58 dBm  Noise level=-95 dBm
          Rx invalid nwid:0  Rx invalid crypt:0  Rx invalid frag:0
          Tx excessive retries:0  Invalid misc:68   Missed beacon:0
"""

# Named capture groups — each (?P<name>...) creates a named slot
ESSID_RE   = re.compile(r'ESSID:"(?P<ssid>[^"]+)"')
SIGNAL_RE  = re.compile(r'Signal level=(?P<rssi>-\d+) dBm')
FREQ_RE    = re.compile(r'Frequency:(?P<freq>[\d.]+) GHz')
BSSID_RE   = re.compile(r'Access Point: (?P<bssid>[0-9A-F:]{17})')

for name, pattern in [("SSID", ESSID_RE), ("RSSI", SIGNAL_RE),
                      ("Freq", FREQ_RE), ("BSSID", BSSID_RE)]:
    m = pattern.search(IWCONFIG_SAMPLE)
    value = m.group(1) if m else "NOT FOUND"
    print(f"  {name:6s} → {value}")
Block 2 — parse_iwconfig() Function

A clean parser function takes raw iwconfig output and returns a structured dict. The caller never sees regex — they just get clean data.

Python 
# ── Block 2: parse_iwconfig() ────────────────────────────────

def parse_iwconfig(output):
    """
    Parse raw iwconfig output string into a structured dict.
    Returns None if the interface doesn't appear to be Wi-Fi connected.
    """
    ssid_m  = re.search(r'ESSID:"(?P<ssid>[^"]+)"', output)
    rssi_m  = re.search(r'Signal level=(?P<rssi>-?\d+) dBm', output)
    freq_m  = re.search(r'Frequency:(?P<freq>[\d.]+) GHz', output)
    bssid_m = re.search(r'Access Point: (?P<bssid>[0-9A-Fa-f:]{17})', output)

    if not ssid_m:
        return None   # Not associated to an AP

    freq = float(freq_m.group("freq")) if freq_m else 0.0
    # Rough channel estimate from frequency (5.18 GHz ≈ Ch 36)
    channel = int((freq - 5.0) * 5) + 36 if freq > 5.0 else 6

    return {
        "ssid":    ssid_m.group("ssid"),
        "rssi":    int(rssi_m.group("rssi")) if rssi_m else None,
        "bssid":   bssid_m.group("bssid") if bssid_m else None,
        "channel": channel,
        "band":    "5 GHz" if freq > 5.0 else "2.4 GHz"
    }

parsed = parse_iwconfig(IWCONFIG_SAMPLE)
print(f"\n[iwconfig parsed] {parsed}")
Block 3 — parse_netsh() for Windows

Windows netsh wlan show interfaces uses a completely different format with Name : Value lines. The same named-group approach works perfectly for this colon-delimited structure.

Python 
# ── Block 3: parse_netsh() (Windows) ─────────────────────────

NETSH_SAMPLE = """
There is 1 interface on the system:

    Name                   : Wi-Fi
    Description            : Intel(R) Wi-Fi 6 AX201
    GUID                   : abc123-...
    Physical address       : 3c:7c:3f:ab:cd:ef
    Interface type         : Primary
    State                  : connected
    SSID                   : CorpWifi-5G
    BSSID                  : aa:bb:cc:01:02:03
    Network type           : Infrastructure
    Radio type             : 802.11ax
    Authentication         : WPA2-Personal
    Channel                : 36
    Receive rate (Mbps)    : 573.5
    Transmit rate (Mbps)   : 573.5
    Signal                 : 74%
"""

def parse_netsh(output):
    """
    Parse Windows 'netsh wlan show interfaces' output.
    The format is 'Key    : Value' lines — easy to capture with regex.
    """
    def field(key):
        """Extract a value from 'Key   : Value' format."""
        m = re.search(rf'{key}\s*:\s*(.+)', output)
        return m.group(1).strip() if m else None

    ssid    = field("SSID")
    bssid   = field("BSSID")
    channel = field("Channel")
    signal  = field("Signal")   # e.g. "74%"

    # Convert signal % to approximate dBm (rough formula)
    rssi = None
    if signal and signal.endswith("%"):
        pct  = int(signal.rstrip("%"))
        rssi = (pct / 2) - 100   # 74% → -63 dBm (approximate)

    return {
        "ssid":    ssid,
        "bssid":   bssid,
        "channel": int(channel) if channel else None,
        "rssi":    rssi
    }

parsed_w = parse_netsh(NETSH_SAMPLE)
print(f"[netsh parsed]   {parsed_w}")
Block 4 — Unified Cross-Platform Parser

The final function auto-detects the OS, runs the right command, and calls the right parser. The calling code never needs to know which OS it's on.

Python 
# ── Block 4: Unified cross-platform parser ───────────────────

def get_current_connection():
    """
    Return the current Wi-Fi connection details as a dict.
    Works on Linux, macOS, and Windows.
    Returns None if not connected or OS is unsupported.
    """
    os_name = platform.system()

    if os_name == "Linux":
        result = subprocess.run(["iwconfig"], capture_output=True, text=True)
        return parse_iwconfig(result.stdout)

    elif os_name == "Darwin":
        cmd = ("/System/Library/PrivateFrameworks/Apple80211.framework"
               "/Versions/Current/Resources/airport -I").split()
        result = subprocess.run(cmd, capture_output=True, text=True)
        # airport -I uses similar key: value format — parse like netsh
        return parse_netsh(result.stdout)

    elif os_name == "Windows":
        result = subprocess.run(
            ["netsh", "wlan", "show", "interfaces"],
            capture_output=True, text=True
        )
        return parse_netsh(result.stdout)

    return None

info = get_current_connection()
if info:
    print(f"\n[Current Connection]")
    for k, v in info.items():
        print(f"  {k:10s}: {v}")
else:
    print("\n[Not connected or OS not supported]")
