The 'Why' — Conceptual Breakdown

What Scapy Can Do That OS Tools Can't

iwconfig tells you the RSSI and SSID of the AP you're connected to. Scapy lets you see every frame flying through the air — management frames from APs you're not connected to, probe requests from client devices, deauthentication frames from potential attackers. This visibility is essential for advanced WLAN testing.

Scapy frames are built like stacked layers.
You combine layers with the / operator: Ether() / IP() / ICMP() builds a complete Ethernet→IP→ICMP ping packet. Each layer has sensible defaults, so you only specify what you want to change. This is called a layer stack and directly mirrors the OSI model.

The 802.11 Frame Structure

An 802.11 Wi-Fi management frame has three parts: a RadioTap header (added by the driver, contains RSSI and channel info), a Dot11 header (MAC addresses, frame type/subtype), and a payload (varies by subtype — Probe Requests have SSID, Beacons have full AP capabilities). Scapy models each of these as a layer class.

Code Walkthrough — Building & Capturing Frames

Create Day11_scapy_intro.py. Install Scapy first: pip install scapy. Note: sending and sniffing frames requires root/administrator privileges.

Block 1 — Building an Ethernet/IP/ICMP Packet

Start with the familiar — an ICMP ping packet. This teaches the layer-stacking syntax before moving to Wi-Fi-specific frames.

Python Day11_scapy_intro.py 
# =============================================================
# Day 11: Introduction to Scapy
# Run with: sudo python Day11_scapy_intro.py
# =============================================================

from scapy.all import (Ether, IP, ICMP, Dot11, Dot11ProbeReq,
                       Dot11Elt, RadioTap, sniff, rdpcap, wrpcap)

# ── Block 1: Building layers with / operator ─────────────────

# Build a ping packet layer by layer
# Ether(): src/dst MAC addresses (auto-filled from interface)
# IP(): src/dst IP addresses
# ICMP(): type=8 means echo request (ping)
ping_pkt = Ether() / IP(dst="8.8.8.8") / ICMP()

print("[Ping Packet]")
ping_pkt.show()   # Prints each layer and field with current values

# Access individual fields directly
print(f"\n  Destination IP  : {ping_pkt[IP].dst}")
print(f"  ICMP Type       : {ping_pkt[ICMP].type} (8=echo-request)")
Block 2 — Building an 802.11 Probe Request Frame

A Probe Request is what your device sends when it's searching for known networks. Building one from scratch in Scapy teaches the 802.11 frame structure intimately — and is used in WLAN testing tools to simulate client device behaviour.

Python 
# ── Block 2: 802.11 Probe Request frame ──────────────────────

# RadioTap: the physical-layer header added by the Wi-Fi driver
# Dot11: the main 802.11 MAC header
#   type=0  → Management frame
#   subtype=4 → Probe Request
# Dot11ProbeReq: probe request body
# Dot11Elt: Information Element (IE) — carries the SSID

probe = (
    RadioTap() /
    Dot11(type=0, subtype=4,
          addr1="ff:ff:ff:ff:ff:ff",   # Broadcast destination
          addr2="aa:bb:cc:dd:ee:ff",   # Source (our MAC)
          addr3="ff:ff:ff:ff:ff:ff") / # BSSID = broadcast for probes
    Dot11ProbeReq() /
    Dot11Elt(ID="SSID", info="CorpWifi-5G")  # The SSID we're probing for
)

print("\n[802.11 Probe Request]")
probe.show()
print(f"\n  Frame length : {len(probe)} bytes")
print(f"  SSID in frame: {probe[Dot11Elt].info.decode()}")
Block 3 — Sniffing Live Packets

sniff() is Scapy's live capture engine. The prn callback fires on every captured packet. count=10 stops after 10 packets. For Wi-Fi frame sniffing (Days 12+) you'll need monitor mode — but for now, this captures Ethernet frames on your active interface.

Python 
# ── Block 3: sniff() — live packet capture ───────────────────

def packet_handler(pkt):
    """
    Called once for every captured packet.
    Access layers with pkt[LayerClass] or pkt.haslayer(LayerClass).
    """
    if pkt.haslayer(IP):
        src = pkt[IP].src
        dst = pkt[IP].dst
        proto = pkt[IP].proto   # 1=ICMP, 6=TCP, 17=UDP
        print(f"  {src:15s} → {dst:15s}  proto={proto}")
    elif pkt.haslayer(Ether):
        print(f"  [Ether] {pkt[Ether].src} → {pkt[Ether].dst}")

print("\n[Sniffing 5 packets on eth0 — Ctrl+C to stop early]")
# iface="eth0" or "wlan0" depending on your system
# count=5 stops automatically after 5 packets
# timeout=10 stops after 10 seconds even if count not reached
captured = sniff(count=5, timeout=10, prn=packet_handler)
print(f"[Captured {len(captured)} packets]")
Block 4 — Reading PCAP Files

PCAP files are the universal format for packet captures — Wireshark, tcpdump, and tshark all use it. Scapy's rdpcap() reads any PCAP file into a Python list of packets, ready for analysis.

Python 
# ── Block 4: Read and write PCAP files ───────────────────────

# Save captured packets to PCAP (viewable in Wireshark)
wrpcap("day11_capture.pcap", captured)
print(f"\n[PCAP] Saved {len(captured)} packets to day11_capture.pcap")

# Read back a PCAP file
packets = rdpcap("day11_capture.pcap")
print(f"[PCAP] Loaded {len(packets)} packets")

# Analyse frame types
for i, pkt in enumerate(packets):
    layers = [layer.__class__.__name__ for layer in pkt.layers()]
    print(f"  Pkt {i+1}: {' / '.join(layers)}")
