Monitor Mode —
Seeing Every Frame in the Air

In managed mode your adapter only captures packets addressed to you. Monitor mode breaks that filter — your adapter captures every 802.11 frame in range. Today you'll enable monitor mode programmatically, extract RSSI from RadioTap headers, and build beacon and probe request handlers that feed into your AP database.

The 'Why' — Conceptual Breakdown

Managed Mode vs. Monitor Mode

In managed mode (normal use), your Wi-Fi adapter is associated to one AP and only processes frames with your MAC address as the destination. It silently discards everything else at the hardware level. In monitor mode, the adapter receives every frame it hears — beacons, probe requests, data frames, management frames from every AP and client nearby. No association is needed.

Monitor mode requires a compatible adapter and root privileges.
Most Linux systems support it via iw dev wlan0 set type monitor. macOS uses the airport utility. Windows requires a special driver (Acrylic Wi-Fi or Wireshark with WinPcap). For this course, a USB Wi-Fi adapter with the Atheros AR9271 or Ralink RT5370 chipset costs under $15 and works out-of-the-box on Linux.

The RadioTap Header

When you capture in monitor mode, every frame arrives with a RadioTap header prepended by the driver. This header contains physical-layer metadata that's not in the 802.11 frame itself: RSSI, data rate, channel frequency, and signal-to-noise ratio. For WLAN testing, the RadioTap RSSI value is the most important — it tells you exactly how strong the signal from that specific AP or client is.

Code Walkthrough — Monitor Mode & Frame Handlers

Create Day12_monitor_mode.py. This requires root/sudo and a monitor-mode capable adapter. Replace "wlan0" with your actual interface name.

Block 1 — Enable/Disable Monitor Mode via subprocess

Always save the interface state before changing it and restore it when done. Leaving an interface in monitor mode disconnects the system from all Wi-Fi — a common mistake that strands you without internet access mid-test.

Python Day12_monitor_mode.py 
# =============================================================
# Day 12: Monitor Mode & 802.11 Frame Sniffing
# Requires: root/sudo + monitor-mode capable Wi-Fi adapter
# =============================================================

import subprocess
import time
from scapy.all import sniff, Dot11, Dot11Beacon, Dot11Elt, RadioTap

def enable_monitor_mode(interface="wlan0"):
    """
    Switch a Wi-Fi interface to monitor mode using iw (Linux).
    Saves current mode so it can be restored later.
    """
    print(f"[+] Enabling monitor mode on {interface}")

    # Bring the interface down before changing mode
    subprocess.run(["ip", "link", "set", interface, "down"], check=True)

    # Set mode to monitor
    subprocess.run(["iw", "dev", interface, "set", "type", "monitor"],
                   check=True)

    # Bring it back up
    subprocess.run(["ip", "link", "set", interface, "up"], check=True)

    print(f"[✓] {interface} is now in monitor mode")

def disable_monitor_mode(interface="wlan0"):
    """Restore interface to managed (normal) mode."""
    print(f"[+] Restoring {interface} to managed mode")
    subprocess.run(["ip", "link", "set", interface, "down"], check=True)
    subprocess.run(["iw", "dev", interface, "set", "type", "managed"], check=True)
    subprocess.run(["ip", "link", "set", interface, "up"], check=True)
    print(f"[✓] {interface} restored to managed mode")
Block 2 — Extracting RSSI from RadioTap

The RadioTap header in Scapy is the RadioTap layer. The RSSI value is in the dBm_AntSignal field. Always check haslayer() before accessing a layer — frames without RadioTap will raise a IndexError if you assume it's always present.

Python 
# ── Block 2: Extract RSSI from RadioTap header ───────────────

def get_rssi(pkt):
    """
    Extract RSSI from the RadioTap header.
    Returns dBm value as int, or None if not available.
    """
    if pkt.haslayer(RadioTap):
        # dBm_AntSignal is the received signal strength in dBm
        return getattr(pkt[RadioTap], "dBm_AntSignal", None)
    return None

# Demonstration with a mock packet
test_pkt = RadioTap(dBm_AntSignal=-62) / Dot11()
print(f"RSSI from packet: {get_rssi(test_pkt)} dBm")
Block 3 — Beacon Frame Handler

Beacon frames are transmitted by APs approximately 10 times per second. They announce the AP's presence and capabilities. Parsing them gives you SSID, BSSID, and RSSI — everything needed to build an AP database.

Python 
# ── Block 3: Beacon frame handler ────────────────────────────

# Dictionary to store discovered APs: {bssid: {ssid, rssi, channel}}
ap_registry = {}

def beacon_handler(pkt):
    """
    Handle 802.11 Beacon frames.
    Dot11Beacon subtype=8 (type=0, subtype=8 in Dot11 layer).
    """
    if not (pkt.haslayer(Dot11Beacon) and pkt.haslayer(Dot11Elt)):
        return

    # BSSID is the transmitting AP's MAC — in addr3 of the Dot11 header
    bssid = pkt[Dot11].addr3
    rssi  = get_rssi(pkt)

    # Walk Information Elements to find SSID (IE ID = 0)
    ssid = None
    ie = pkt[Dot11Elt]
    while ie:
        if ie.ID == 0:    # ID 0 = SSID Information Element
            ssid = ie.info.decode("utf-8", errors="replace")
            break
        ie = ie.payload.getlayer(Dot11Elt)  # Move to next IE

    if ssid and bssid:
        ap_registry[bssid] = {"ssid": ssid, "rssi": rssi, "bssid": bssid}
        print(f"  [Beacon] {ssid:25s} {bssid}  RSSI: {rssi} dBm")
Block 4 — Sniffing Beacon Frames

With the handler defined, the sniff() call connects it to live traffic. The lfilter parameter pre-filters packets in Python before passing them to prn — this is more flexible than BPF filters for complex 802.11 logic.

Python 
# ── Block 4: Start sniffing for 15 seconds ───────────────────

IFACE = "wlan0mon"   # Monitor mode interface name (may be wlan0 on some systems)

print(f"\n[+] Sniffing beacons on {IFACE} for 15 seconds...")

try:
    sniff(
        iface=IFACE,
        prn=beacon_handler,
        # lfilter: only pass 802.11 management frames (type=0)
        lfilter=lambda p: p.haslayer(Dot11) and p[Dot11].type == 0,
        timeout=15,
        store=False   # Don't accumulate packets in RAM (saves memory)
    )
finally:
    # Always restore interface even if sniffing is interrupted
    print(f"\n[+] Scan complete. {len(ap_registry)} APs discovered:")
    for bssid, info in sorted(ap_registry.items(),
                               key=lambda x: x[1].get("rssi", -999),
                               reverse=True):
        print(f"  {info['ssid']:25s} {bssid}  RSSI: {info['rssi']} dBm")
