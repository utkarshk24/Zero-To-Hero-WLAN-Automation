The 'Why' — Conceptual Breakdown

The 802.11 Frame Type/Subtype System

Every 802.11 frame has a 2-bit type field and a 4-bit subtype field in its MAC header. Type 0 = Management, Type 1 = Control, Type 2 = Data. Within management frames, subtype 0 = Association Request, subtype 4 = Probe Request, subtype 8 = Beacon, subtype 12 = Deauthentication. Knowing this table is essential for writing precise Scapy filters.

lfilter vs. BPF: Use lfilter for 802.11 logic.
BPF (Berkeley Packet Filter) strings like "wlan type mgt" work at the kernel level but have limited 802.11 awareness. Scapy's lfilter parameter accepts a Python lambda with full access to every decoded field — far more expressive for WLAN automation use cases.

The Deauth Storm Attack

A 802.11 Deauthentication frame (type=0, subtype=12) can be sent by anyone in monitor mode — it doesn't require any authentication. An attacker can flood the air with deauth frames targeting a specific client or all clients, causing repeated disconnections. Detecting a deauth storm (more than N deauth frames per second from the same source) is a real-world security monitoring use case that you'll implement today.

Block 1 — The 802.11 Type/Subtype Reference Table

Building a name lookup dict lets your code print human-readable frame names instead of raw numbers, and makes filters self-documenting.

Python Day14_frame_filters.py 
# =============================================================
# Day 14: Scapy Frame Filters — type/subtype targeting
# =============================================================

from scapy.all import sniff, Dot11, Dot11Deauth, RadioTap
from collections import Counter, defaultdict
import time

# 802.11 Frame type/subtype name table
# Format: (type, subtype) → human name
FRAME_NAMES = {
    (0, 0):  "Association Request",
    (0, 1):  "Association Response",
    (0, 2):  "Reassociation Request",
    (0, 4):  "Probe Request",
    (0, 5):  "Probe Response",
    (0, 8):  "Beacon",
    (0, 10): "Disassociation",
    (0, 11): "Authentication",
    (0, 12): "Deauthentication",
    (1, 8):  "Block ACK Request",
    (1, 9):  "Block ACK",
    (1, 11): "RTS",
    (1, 12): "CTS",
    (1, 13): "ACK",
    (2, 0):  "Data",
    (2, 4):  "Null Data",
    (2, 8):  "QoS Data",
}

def get_frame_name(pkt):
    """Return a human-readable name for a Dot11 frame."""
    if not pkt.haslayer(Dot11):
        return "Unknown"
    t  = pkt[Dot11].type
    st = pkt[Dot11].subtype
    return FRAME_NAMES.get((t, st), f"Type{t}/Sub{st}")

# Quick demo
from scapy.all import Dot11Beacon
beacon = Dot11(type=0, subtype=8) / Dot11Beacon()
print(f"Frame name: {get_frame_name(beacon)}")
Block 2 — lfilter Lambdas for Common Frame Types

These lambda filters are used as the lfilter= argument to sniff(). They run on every captured packet before the prn handler — only packets that return True are passed through.

Python 
# ── Block 2: lfilter lambdas ──────────────────────────────────

# Filter: only Beacon frames (Management type=0, subtype=8)
is_beacon = lambda p: (p.haslayer(Dot11) and
                       p[Dot11].type == 0 and p[Dot11].subtype == 8)

# Filter: only Probe Requests (Management type=0, subtype=4)
is_probe_req = lambda p: (p.haslayer(Dot11) and
                          p[Dot11].type == 0 and p[Dot11].subtype == 4)

# Filter: only Data frames (type=2, any subtype)
is_data = lambda p: p.haslayer(Dot11) and p[Dot11].type == 2

# Filter: only Deauthentication frames (type=0, subtype=12)
is_deauth = lambda p: (p.haslayer(Dot11) and
                       p[Dot11].type == 0 and p[Dot11].subtype == 12)

# Filter: any Management frame (type=0)
is_mgmt = lambda p: p.haslayer(Dot11) and p[Dot11].type == 0

print("Filters defined:")
for name in ["is_beacon", "is_probe_req", "is_data", "is_deauth", "is_mgmt"]:
    print(f"  {name}")
Block 3 — Frame Counter by Type

A frame counter is the simplest useful analysis — it tells you what the RF environment looks like and whether there's unusual traffic (like an excess of deauth frames).

Python 
# ── Block 3: Frame counter ────────────────────────────────────

frame_counter = Counter()

def counting_handler(pkt):
    """Count each frame type as it arrives."""
    name = get_frame_name(pkt)
    frame_counter[name] += 1

IFACE = "wlan0mon"
print(f"\n[+] Counting frames on {IFACE} for 10 seconds...")
sniff(iface=IFACE, prn=counting_handler,
      lfilter=is_mgmt, timeout=10, store=False)

print("\n[Frame Counts]")
for frame_type, count in frame_counter.most_common():
    bar = "█" * min(count, 40)
    print(f"  {frame_type:25s} {count:4d}  {bar}")
Block 4 — Deauth Storm Detector

A deauth storm is when more than a threshold number of deauth frames arrive from the same source MAC within a short time window. This detector tracks deauth counts per source and alerts when the threshold is crossed — a real security monitoring pattern.

Python 
# ── Block 4: Deauth storm detector ───────────────────────────

DEAUTH_THRESHOLD = 10   # Deauths per 5-second window = potential attack
deauth_counts    = defaultdict(int)
window_start     = time.time()
alerted_sources  = set()

def deauth_detector(pkt):
    """
    Detect deauthentication storms.
    Alerts when a single source sends more than DEAUTH_THRESHOLD
    deauth frames in a 5-second sliding window.
    """
    global window_start, deauth_counts, alerted_sources

    if not (pkt.haslayer(Dot11) and pkt[Dot11].type == 0
            and pkt[Dot11].subtype == 12):
        return

    # Reset window every 5 seconds
    now = time.time()
    if now - window_start > 5.0:
        deauth_counts.clear()
        alerted_sources.clear()
        window_start = now

    src = pkt[Dot11].addr2   # Source MAC
    dst = pkt[Dot11].addr1   # Target MAC (ff:ff:ff:ff:ff:ff = broadcast attack)
    deauth_counts[src] += 1

    if (deauth_counts[src] >= DEAUTH_THRESHOLD
            and src not in alerted_sources):
        alerted_sources.add(src)
        print(f"\n  ⚠ DEAUTH STORM DETECTED!")
        print(f"  Source : {src}")
        print(f"  Target : {dst}")
        print(f"  Count  : {deauth_counts[src]} frames in <5 seconds\n")

print(f"\n[+] Deauth storm detector running for 30 seconds...")
sniff(iface=IFACE, prn=deauth_detector,
      lfilter=is_deauth, timeout=30, store=False)
