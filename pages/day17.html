The 'Why' — Conceptual Breakdown

Why Scan Before Connecting?

A connection test that simply calls "connect to CorpWifi-5G" will fail if the AP isn't visible — but the failure reason will be cryptic: timeout, association refused, or simply no output. If you scan first and confirm the SSID is visible with adequate RSSI before attempting the connection, your test failures become diagnostic: "AP not found" vs. "AP found but connection failed" vs. "Connection succeeded but DHCP failed."

A scan is a prerequisite, not a step.
Think of scan_until_found(ssid) as a gate that your test must pass before attempting a connection. If the AP doesn't appear within the timeout, the test is marked as SKIP (environment issue) rather than FAIL (software bug) — a crucial distinction in CI reporting.

Triggering a Fresh Scan

Network managers cache scan results. On Linux, nmcli dev wifi list returns cached results unless you force a fresh scan with nmcli dev wifi list --rescan yes. On macOS, the airport -s command always returns a live scan. Understanding the difference prevents you from building automation that reads stale data and reports false positives.

Block 1 — nmcli_scan() with Forced Rescan

The --rescan yes flag forces NetworkManager to send a new probe request sequence before returning results. This adds about 2-3 seconds but guarantees fresh data.

Python Day17_scan_ssids.py 
# =============================================================
# Day 17: Programmatic SSID Scanning
# =============================================================

import subprocess
import platform
import time
import re

def nmcli_scan(trigger_rescan=True):
    """
    Get available Wi-Fi networks via nmcli (Linux/NetworkManager).
    trigger_rescan=True forces a fresh scan (slower but accurate).
    Returns a list of dicts with ssid, bssid, signal, channel, security.
    """
    # Build command — --rescan yes triggers a fresh OTA scan
    rescan = "yes" if trigger_rescan else "no"
    cmd = ["nmcli", "--terse", "--fields",
           "SSID,BSSID,SIGNAL,CHAN,SECURITY",
           "dev", "wifi", "list", "--rescan", rescan]

    result = subprocess.run(cmd, capture_output=True, text=True, timeout=30)

    if result.returncode != 0:
        print(f"[nmcli ERROR] {result.stderr.strip()}")
        return []

    networks = []
    for line in result.stdout.strip().splitlines():
        # nmcli -t separates fields with ':' but BSSID itself contains ':'
        # Use maxsplit cleverly or split by known field count
        parts = line.split(":")
        if len(parts) >= 5:
            networks.append({
                "ssid":     parts[0],
                "signal":   int(parts[7]) if len(parts) > 7 and parts[7].isdigit() else 0,
                "channel":  int(parts[8]) if len(parts) > 8 and parts[8].isdigit() else 0,
                "security": parts[9] if len(parts) > 9 else "Unknown"
            })
    return networks
Block 2 — airport_scan() for macOS

Apple's airport utility produces column-aligned output. The regex approach handles variable-width SSID and BSSID fields correctly.

Python 
def airport_scan():
    """
    Get available Wi-Fi networks via Apple's airport utility (macOS).
    Output format: SSID  BSSID  RSSI  CHANNEL  HT  CC  SECURITY
    """
    airport = ("/System/Library/PrivateFrameworks/Apple80211.framework"
               "/Versions/Current/Resources/airport")
    result = subprocess.run([airport, "-s"],
                            capture_output=True, text=True, timeout=15)
    networks = []
    for line in result.stdout.splitlines()[1:]:   # Skip header row
        # airport uses fixed-width columns — split on 2+ spaces
        parts = re.split(r"\s{2,}", line.strip())
        if len(parts) >= 4:
            try:
                networks.append({
                    "ssid":     parts[0],
                    "bssid":    parts[1],
                    "rssi":     int(parts[2]),
                    "channel":  int(parts[3].split(",")[0]),  # "6,+1" → 6
                    "security": parts[6] if len(parts) > 6 else "Unknown"
                })
            except (ValueError, IndexError):
                continue
    return networks
Block 3 — Cross-Platform scan() Dispatcher

The dispatcher selects the right scan function for the current OS, returning a consistent list of dicts regardless of platform.

Python 
def scan():
    """
    Cross-platform SSID scan. Returns list of AP dicts.
    Each dict has: ssid, rssi (where available), channel, security.
    """
    os_name = platform.system()
    if os_name == "Linux":
        return nmcli_scan()
    elif os_name == "Darwin":
        return airport_scan()
    else:
        print(f"[scan] Unsupported OS: {os_name}")
        return []

networks = scan()
print(f"[Scan] Found {len(networks)} networks:")
for n in sorted(networks, key=lambda x: x.get("signal", x.get("rssi", 0)), reverse=True):
    print(f"  {n.get('ssid','?'):25s} Ch{n.get('channel','?'):3}  sig={n.get('signal', n.get('rssi','?'))}")
Block 4 — scan_until_found() Polling Function

This is the most important function of today. It repeatedly scans and checks whether the target SSID has appeared. The timeout and interval parameters make it configurable — short intervals for testing, longer for CI where scan triggering is slower.

Python 
def scan_until_found(target_ssid, timeout=30, interval=5, min_rssi=None):
    """
    Poll Wi-Fi scans until the target SSID appears (or timeout expires).

    Args:
        target_ssid: SSID string to look for
        timeout:     Max seconds to wait (default 30)
        interval:    Seconds between scans (default 5)
        min_rssi:    If set, AP must also meet this RSSI threshold

    Returns:
        AP dict if found, None if timed out.
    """
    deadline = time.time() + timeout
    attempt  = 0

    while time.time() < deadline:
        attempt += 1
        print(f"  [Scan {attempt}] Searching for '{target_ssid}'...")
        networks = scan()

        for ap in networks:
            if ap.get("ssid") == target_ssid:
                rssi_ok = True
                if min_rssi is not None:
                    rssi_val = ap.get("rssi", ap.get("signal", -100))
                    rssi_ok  = rssi_val >= min_rssi

                if rssi_ok:
                    print(f"  [✓] Found '{target_ssid}' on scan {attempt}")
                    return ap
                else:
                    print(f"  [→] '{target_ssid}' found but RSSI too low")

        remaining = int(deadline - time.time())
        print(f"  [→] Not found. {remaining}s remaining. Waiting {interval}s...")
        time.sleep(interval)

    print(f"  [✗] '{target_ssid}' not found within {timeout}s")
    return None

# Example usage
ap = scan_until_found("CorpWifi-5G", timeout=15, interval=3)
if ap:
    print(f"\nTarget AP ready: {ap}")
