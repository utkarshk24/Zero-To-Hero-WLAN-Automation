The 'Why' — Conceptual Breakdown

What's Inside a Beacon Frame

The 802.11 beacon frame body starts with a fixed 12-byte header containing the timestamp (microseconds since AP boot), beacon interval (usually 100 TUs ≈ 102.4ms), and capability information (a 16-bit flags field indicating whether the AP supports privacy/WEP, short preamble, spectrum management, and more).

After the fixed header comes a variable-length chain of Information Elements (IEs) — tagged data structures identified by a one-byte ID number. ID 0 = SSID. ID 1 = Supported Rates. ID 3 = Current Channel. ID 48 = RSN (security). Parsing these IEs gives you the complete picture of an AP's capabilities.

Beacon interval reveals AP load and configuration quality.
A well-configured AP beacons every 100 TUs (102.4ms). APs beaconing at 200ms or more may be overloaded or misconfigured. Automated testing can verify beacon interval compliance as part of a deployment validation checklist.

Block 1 — Beacon Frame Structure in Scapy

In Scapy, a captured beacon has three layers: RadioTap (physical layer metadata), Dot11 (MAC header), and Dot11Beacon (the beacon body with timestamp, interval, and capability info).

Python Day18_parse_beacon.py 
# =============================================================
# Day 18: Parsing Beacon Frames
# =============================================================

from scapy.all import (sniff, Dot11, Dot11Beacon, Dot11Elt,
                       RadioTap, rdpcap)

def decode_capabilities(cap_info):
    """
    Decode the 16-bit capability information field from a beacon.
    Returns a dict of human-readable capability flags.
    """
    return {
        "ess":           bool(cap_info & 0x0001),  # Infrastructure BSS
        "ibss":          bool(cap_info & 0x0002),  # Ad-hoc IBSS
        "privacy":       bool(cap_info & 0x0010),  # WEP (legacy encryption bit)
        "short_preamble":bool(cap_info & 0x0020),
        "spectrum_mgmt": bool(cap_info & 0x0100),  # DFS/TPC support
    }

# Test with a sample capability value
caps = decode_capabilities(0x0431)
print("[Capabilities]")
for cap, val in caps.items():
    print(f"  {cap:20s}: {val}")
Block 2 — Walking Information Elements

Scapy models each IE as a Dot11Elt layer chained in a linked list. Walking the chain with ie.payload.getlayer(Dot11Elt) gives you all IEs in order.

Python 
def walk_ies(pkt):
    """
    Walk all Information Elements in a beacon and return a dict.
    Key = IE ID number, Value = raw bytes of the IE data.
    """
    ie_dict = {}
    ie = pkt.getlayer(Dot11Elt)
    while ie:
        ie_dict[ie.ID] = ie.info
        ie = ie.payload.getlayer(Dot11Elt)
    return ie_dict

Block 3 — Full parse_beacon() Function

This is the complete parser that extracts every useful field from a beacon frame into a clean Python dict ready for storage and analysis.

Python 
def parse_beacon(pkt):
    """
    Fully parse a Scapy beacon frame packet.
    Returns a dict with all extracted AP information.
    """
    if not pkt.haslayer(Dot11Beacon):
        return None

    bssid     = pkt[Dot11].addr3
    rssi      = getattr(pkt.getlayer(RadioTap), "dBm_AntSignal", None)
    beacon    = pkt[Dot11Beacon]

    # Beacon interval is in TUs (1 TU = 1024 microseconds ≈ 1.024ms)
    interval_ms = beacon.beacon_interval * 1.024

    # Decode capability information field
    caps = decode_capabilities(int(beacon.cap))

    # Walk IEs to extract SSID and channel
    ies    = walk_ies(pkt)
    ssid   = ies.get(0, b"").decode("utf-8", errors="replace").strip()
    # IE 3 = Current Channel (1 byte)
    channel_bytes = ies.get(3, b"\x00")
    channel = channel_bytes[0] if channel_bytes else None

    # Detect PHY generation from IEs
    has_ht  = 61 in ies    # HT Operation = 802.11n
    has_vht = 191 in ies   # VHT Caps     = 802.11ac
    phy = "802.11ax" if has_vht else ("802.11n" if has_ht else "802.11a/g")

    return {
        "ssid":        ssid,
        "bssid":       bssid,
        "rssi":        rssi,
        "channel":     channel,
        "interval_ms": round(interval_ms, 1),
        "privacy":     caps["privacy"],
        "phy":         phy,
        "rsn":         48 in ies,   # True if RSN IE present (WPA2/3)
    }
Block 4 — update_ap_db() Live Database

The live database merges new beacon data with existing entries, tracking RSSI history and updating the last-seen timestamp on every new beacon.

Python 
import datetime

ap_db = {}   # {bssid: {parsed fields + rssi_history + counts}}

def update_ap_db(pkt):
    """Update the live AP database with data from a new beacon."""
    info = parse_beacon(pkt)
    if not info or not info["bssid"]:
        return

    bssid = info["bssid"]
    now   = datetime.datetime.now()

    if bssid not in ap_db:
        ap_db[bssid] = {**info,
                        "rssi_history": [],
                        "beacon_count": 0,
                        "first_seen":   now}
    entry = ap_db[bssid]
    entry["beacon_count"] += 1
    entry["last_seen"]     = now
    if info["rssi"] is not None:
        entry["rssi_history"].append(info["rssi"])
    # Keep only last 100 RSSI samples (rolling window)
    entry["rssi_history"] = entry["rssi_history"][-100:]

IFACE = "wlan0mon"
print(f"[+] Building live AP database — sniffing beacons for 20s...")
sniff(iface=IFACE, prn=update_ap_db,
      lfilter=lambda p: p.haslayer(Dot11Beacon),
      timeout=20, store=False)
print(f"[+] Database: {len(ap_db)} APs")
