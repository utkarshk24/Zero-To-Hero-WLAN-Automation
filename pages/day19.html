The 'Why' — Conceptual Breakdown

Why Decode IEs Yourself?

OS tools report security as a simple string: "WPA2-Personal" or "Open". But that hides critical details. An AP might report "WPA2" while actually using TKIP (deprecated, vulnerable) instead of CCMP. Another might claim WPA3 but have Transition Mode enabled, allowing WPA2 connections — a security downgrade risk. Decoding the RSN IE yourself gives you the raw truth: exactly which cipher suites and authentication methods the AP advertises.

AKM Suite Selectors identify the authentication method.
AKM 1 = 802.1X/EAP (Enterprise), AKM 2 = PSK (WPA2-Personal), AKM 8 = SAE (WPA3), AKM 18 = OWE (Opportunistic Wireless Encryption, WPA3-Open). The AKM suite bytes in the RSN IE tell you exactly what authentication the AP supports — no guessing required.

The RSN Information Element Structure

The RSN IE (ID 48) starts with a 2-byte version field (always 1), followed by a 4-byte Group Cipher Suite, a 2-byte Pairwise Cipher Suite count, N×4-byte pairwise suites, a 2-byte AKM suite count, and N×4-byte AKM suites. Each suite selector is a 3-byte OUI followed by a 1-byte suite type. The OUI 00:0F:AC identifies IEEE 802.11i suites.

Block 2 — decode_rsn_ie() Binary Parser

struct.unpack_from() reads typed values from a byte buffer at a given offset. The format string "<H" means: little-endian unsigned short (2 bytes). This is exactly how the RSN IE binary structure is defined in the 802.11 specification.

Python 
def decode_rsn_ie(rsn_bytes):
    """
    Decode the raw bytes of an RSN Information Element.
    Returns: {version, group_cipher, pairwise_ciphers, akm_suites, pmf_required}
    """
    if len(rsn_bytes) < 4:
        return None

    offset = 0
    # Version: 2 bytes, little-endian unsigned short
    version = struct.unpack_from("<H", rsn_bytes, offset)[0]
    offset += 2

    # Group Cipher Suite: 3-byte OUI + 1-byte type
    group_oui  = rsn_bytes[offset:offset+3]
    group_type = rsn_bytes[offset+3]
    group_cipher = CIPHER_SUITES.get(group_type, f"Unknown({group_type})")
    offset += 4

    # Pairwise Cipher Suites
    if offset + 2 > len(rsn_bytes):
        return {"version": version, "group_cipher": group_cipher,
                "pairwise_ciphers": [], "akm_suites": [], "pmf_required": False}

    pw_count = struct.unpack_from("<H", rsn_bytes, offset)[0]
    offset += 2
    pairwise_ciphers = []
    for _ in range(pw_count):
        if offset + 4 > len(rsn_bytes):
            break
        cipher_type = rsn_bytes[offset+3]
        pairwise_ciphers.append(CIPHER_SUITES.get(cipher_type, f"Unk({cipher_type})"))
        offset += 4

    # AKM Suites
    akm_suites = []
    if offset + 2 <= len(rsn_bytes):
        akm_count = struct.unpack_from("<H", rsn_bytes, offset)[0]
        offset += 2
        for _ in range(akm_count):
            if offset + 4 > len(rsn_bytes):
                break
            akm_type = rsn_bytes[offset+3]
            akm_suites.append(AKM_SUITES.get(akm_type, f"Unk({akm_type})"))
            offset += 4

    # RSN Capabilities (2 bytes) — PMF flags
    pmf_required = False
    if offset + 2 <= len(rsn_bytes):
        rsn_caps = struct.unpack_from("<H", rsn_bytes, offset)[0]
        pmf_required = bool(rsn_caps & 0x0040)   # Bit 6 = MFP Required

    return {
        "version":          version,
        "group_cipher":     group_cipher,
        "pairwise_ciphers": pairwise_ciphers,
        "akm_suites":       akm_suites,
        "pmf_required":     pmf_required,
    }
Block 3 — classify_security()

With the RSN IE decoded, classification is straightforward: check the AKM suites to determine the authentication method, then combine with the pairwise cipher to produce a clean human-readable security label.

Python 
def classify_security(ies):
    """
    Classify AP security from its IE dict (from walk_ies()).
    Returns: 'WPA3', 'WPA2-Enterprise', 'WPA2-Personal', 'WPA2-TKIP', or 'Open'
    """
    if 48 not in ies:
        return "Open"   # No RSN IE = no WPA2/3

    rsn = decode_rsn_ie(ies[48])
    if not rsn:
        return "Open"

    akm_names = " ".join(rsn["akm_suites"])

    if "SAE" in akm_names or "OWE" in akm_names:
        return "WPA3"
    if "Enterprise" in akm_names or "802.1X" in akm_names:
        return "WPA2-Enterprise"
    if "PSK" in akm_names:
        # Downgrade flag: TKIP pairwise cipher is deprecated
        if "TKIP" in rsn["pairwise_ciphers"] and "CCMP" not in rsn["pairwise_ciphers"]:
            return "WPA2-TKIP"   # Warning: TKIP-only, vulnerable
        return "WPA2-Personal"

    return "Unknown"
