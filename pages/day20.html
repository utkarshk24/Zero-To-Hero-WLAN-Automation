The 'Why' — Conceptual Breakdown

The Full Connection Lifecycle

A Wi-Fi connection involves multiple sequential phases: (1) scanning for the SSID, (2) sending a Probe Request, (3) Authentication exchange, (4) Association, (5) 4-Way Handshake (WPA2 key exchange), (6) DHCP Request/Offer, (7) IP assignment. Manually clicking "Connect" collapses all these into one button press. Automated testing needs to verify each phase can complete within acceptable timing thresholds.

nmcli is NetworkManager's command-line interface.
On modern Linux systems, NetworkManager handles Wi-Fi connections. Using nmcli from Python gives you a clean API to trigger connections, check connection status, and disconnect — without needing to manage WPA supplicant configuration files directly. It also handles credential storage securely via the system keyring.

Polling vs. Event-Driven

After triggering a connection, you don't know exactly when the IP will be assigned. The clean approach is to poll every 500ms, checking for a valid IP address with a reasonable timeout (typically 15–30 seconds). This is preferable to using a fixed time.sleep(5) — polling gives you accurate timing and fails fast if the connection is refused immediately.

Block 1 — connect_wpa2() via nmcli

nmcli's dev wifi connect command handles the full connection sequence. The --wait 0 flag makes it non-blocking — it triggers the connection and returns immediately so we can monitor progress ourselves.

import subprocess
import time
import re
import netifaces   # pip install netifaces

def connect_wpa2(ssid, password, interface="wlan0", timeout=30):
    """
    Connect to a WPA2-Personal network using nmcli.
    Uses --wait 0 so we can poll for IP assignment ourselves.

    Returns: (success: bool, message: str)
    """
    print(f"[→] Connecting to '{ssid}' on {interface}...")

    # First, ensure we're disconnected from any current network
    subprocess.run(["nmcli", "dev", "disconnect", interface],
                   capture_output=True)

    # Trigger the connection — nmcli handles the 4-way handshake
    result = subprocess.run(
        ["nmcli", "--wait", str(timeout), "dev", "wifi", "connect",
         ssid, "password", password, "ifname", interface],
        capture_output=True, text=True, timeout=timeout + 5
    )

    if result.returncode == 0:
        return True, f"Connected to '{ssid}'"
    else:
        # Extract the meaningful part of nmcli's error message
        error = result.stderr.strip() or result.stdout.strip()
        return False, f"Connection failed: {error}"

Block 2 — wait_for_ip() with Polling

After triggering a connection, we poll for an IP address using netifaces. The function returns the IP and elapsed time, giving you association timing data for your test reports.

Python 
def wait_for_ip(interface="wlan0", timeout=15, poll_interval=0.5):
    """
    Poll until the interface has a valid (non-APIPA) IPv4 address.
    APIPA addresses (169.254.x.x) indicate DHCP failure.

    Returns: (ip_address: str or None, elapsed_seconds: float)
    """
    start    = time.time()
    deadline = start + timeout

    while time.time() < deadline:
        try:
            addrs = netifaces.ifaddresses(interface)
            ipv4  = addrs.get(netifaces.AF_INET, [{}])
            ip    = ipv4[0].get("addr", "")

            # Valid IP = assigned and not APIPA (169.254.x.x)
            if ip and not ip.startswith("169.254."):
                elapsed = round(time.time() - start, 2)
                return ip, elapsed

        except (ValueError, KeyError):
            pass   # Interface may not exist yet — keep polling

        time.sleep(poll_interval)

    elapsed = round(time.time() - start, 2)
    return None, elapsed

Block 3 — test_connection() Full Cycle

The complete test function: connect, wait for IP, ping the gateway. Returns a structured result dict that your pytest test cases can assert against.

Python 
def get_gateway(interface="wlan0"):
    """Get the default gateway IP for the given interface."""
    result = subprocess.run(["ip", "route", "show", "dev", interface],
                            capture_output=True, text=True)
    m = re.search(r"default via ([\d.]+)", result.stdout)
    return m.group(1) if m else None

def ping_host(host, count=3, timeout=5):
    """
    Ping a host and return (success: bool, avg_rtt_ms: float or None).
    """
    result = subprocess.run(
        ["ping", "-c", str(count), "-W", str(timeout), host],
        capture_output=True, text=True
    )
    if result.returncode != 0:
        return False, None

    # Parse average RTT from 'rtt min/avg/max/mdev = X/Y/Z/W ms'
    m = re.search(r"min/avg/max/mdev = [\d.]+/([\d.]+)/", result.stdout)
    avg_rtt = float(m.group(1)) if m else None
    return True, avg_rtt

def test_connection(ssid, password, interface="wlan0"):
    """
    Full WPA2 connection test: connect → wait for IP → ping gateway.
    Returns a complete result dict suitable for pytest assertions.
    """
    result = {
        "ssid": ssid, "interface": interface,
        "connected": False, "ip": None, "ip_time_s": None,
        "gateway": None, "ping_ok": False, "ping_rtt_ms": None,
        "overall": "FAIL"
    }

    # Step 1: Connect
    ok, msg = connect_wpa2(ssid, password, interface)
    if not ok:
        result["error"] = msg
        return result
    result["connected"] = True

    # Step 2: Wait for IP
    ip, ip_time = wait_for_ip(interface, timeout=20)
    result["ip"], result["ip_time_s"] = ip, ip_time
    if not ip:
        result["error"] = "DHCP timeout — no IP assigned"
        return result

    # Step 3: Ping gateway
    gw = get_gateway(interface)
    result["gateway"] = gw
    if gw:
        ping_ok, rtt = ping_host(gw)
        result["ping_ok"], result["ping_rtt_ms"] = ping_ok, rtt

    result["overall"] = "PASS" if result["ping_ok"] else "FAIL"
    return result
