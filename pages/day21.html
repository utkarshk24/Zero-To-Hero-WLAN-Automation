The 'Why' — Conceptual Breakdown

WPA2 Weakness: Offline Dictionary Attacks

WPA2-PSK is vulnerable to offline dictionary attacks. An attacker captures the 4-Way Handshake (just 4 frames, visible to anyone in monitor mode), takes it home, and runs millions of password guesses per second against it with a GPU. Weak passwords can be cracked in hours.

WPA3-SAE eliminates this vulnerability. The Dragonfly key exchange proves knowledge of the password without revealing anything that can be attacked offline. Even a full capture of the SAE exchange yields nothing to a passive attacker.

WPA3 Transition Mode: backward-compatible and secure.
An AP in Transition Mode advertises both SAE (for WPA3 clients) and PSK (for WPA2 clients) in its RSN IE. WPA3 clients negotiate SAE automatically; WPA2-only clients fall back to PSK. PMF is required for SAE connections and optional for PSK connections in Transition Mode.

Code Walkthrough — Detecting WPA3, Connecting with SAE, Verifying PMF

Create Day21_wpa3_sae.py. This builds on Day 19's security classification to detect WPA3 modes, then connects with the correct key management settings.

Block 1 — detect_wpa3_mode() via nmcli

nmcli's RSN-FLAGS field contains a space-separated list of the security options the AP supports. Checking for sae vs. psk tells you exactly which authentication modes are offered.

Python Day21_wpa3_sae.py 
# =============================================================
# Day 21: WPA3 & SAE — Modern Security Automation
# =============================================================

import subprocess
import re

def detect_wpa3_mode(ssid):
    """
    Query an AP's security capabilities using nmcli.
    Returns: 'wpa3-only', 'transition', 'wpa2-only', or 'open'
    """
    result = subprocess.run(
        ["nmcli", "--terse", "--fields",
         "SSID,SECURITY,RSN-FLAGS",
         "dev", "wifi", "list", "--rescan", "yes"],
        capture_output=True, text=True, timeout=30
    )

    for line in result.stdout.splitlines():
        parts = line.split(":")
        if len(parts) < 3:
            continue
        if parts[0] != ssid:
            continue
        rsn_flags = parts[2].lower()
        has_sae = "sae" in rsn_flags
        has_psk = "psk" in rsn_flags

        if has_sae and has_psk:
            return "transition"   # Both = WPA3 Transition Mode
        elif has_sae:
            return "wpa3-only"
        elif has_psk:
            return "wpa2-only"
        return "open"
    return "open"
Block 2 — connect_wpa3() with SAE Key Management

When connecting to WPA3, nmcli must be told to use SAE key management explicitly. Without this, it may fall back to PSK — which won't use the secure SAE handshake even on Transition Mode APs.

Python 
def connect_wpa3(ssid, password, interface="wlan0", timeout=30):
    """
    Connect to a WPA3 AP using SAE (Dragonfly) key management.
    Creates a temporary NM connection profile with explicit SAE settings.
    PMF is set to 'required' (value=2) as mandated by WPA3.
    """
    print(f"[WPA3] Connecting to '{ssid}' with SAE...")

    # Create a new NM connection profile for this WPA3 AP
    cmd = [
        "nmcli", "connection", "add",
        "type",         "wifi",
        "ifname",       interface,
        "ssid",         ssid,
        # key-mgmt=sae forces Dragonfly / SAE authentication
        "802-11-wireless-security.key-mgmt",  "sae",
        "802-11-wireless-security.psk",       password,
        # pmf=2 means 'required' — management frames must be protected
        "802-11-wireless-security.pmf",       "2",
        "connection.id",  f"wpa3-test-{ssid}",
    ]
    add = subprocess.run(cmd, capture_output=True, text=True)
    if add.returncode != 0:
        return False, f"Profile creation failed: {add.stderr.strip()}"

    # Activate the profile
    up = subprocess.run(
        ["nmcli", "--wait", str(timeout),
         "connection", "up", f"wpa3-test-{ssid}", "ifname", interface],
        capture_output=True, text=True, timeout=timeout + 5
    )
    if up.returncode == 0:
        return True, "Connected via SAE"

    # Clean up failed profile
    subprocess.run(["nmcli", "connection", "delete", f"wpa3-test-{ssid}"],
                   capture_output=True)
    return False, up.stderr.strip() or "Connection failed"
Block 3 — check_pmf_active()

After connecting, verify that PMF is active. A WPA3 connection without PMF active is a misconfiguration — deauth attacks would still work despite the secure handshake.

Python 
def check_pmf_active(interface="wlan0"):
    """
    Verify Protected Management Frames are active on the current connection.
    Returns: (active: bool, details: str)
    """
    result = subprocess.run(["iw", "dev", interface, "link"],
                            capture_output=True, text=True)
    if "PMF on" in result.stdout or "MFP active" in result.stdout:
        return True, "PMF is active — management frames are protected"

    # Fallback: check NM connection profile PMF setting
    nm_result = subprocess.run(
        ["nmcli", "-t", "-f", "802-11-wireless-security.pmf",
         "con", "show", "--active"],
        capture_output=True, text=True
    )
    if "required" in nm_result.stdout.lower():
        return True, "PMF set to required in active connection profile"

    return False, "PMF is not active — management frames are unprotected"
Block 4 — wpa3_test_flow() Orchestrator

The test flow detects the AP's WPA3 support, connects with the appropriate method, then verifies PMF. This is the function your pytest test cases will call.

Python 
def wpa3_test_flow(ssid, password, interface="wlan0"):
    """
    Full WPA3 test: detect mode → connect appropriately → verify PMF.
    Returns a result dict for pytest assertions.
    """
    result = {"ssid": ssid, "mode": None, "connected": False,
              "pmf_active": False, "overall": "FAIL"}

    mode = detect_wpa3_mode(ssid)
    result["mode"] = mode
    print(f"[Mode] {ssid} → {mode}")

    if mode in ("wpa3-only", "transition"):
        ok, msg = connect_wpa3(ssid, password, interface)
    else:
        result["overall"] = "SKIP"
        return result   # Not a WPA3 AP — skip this test

    result["connected"] = ok
    print(f"[Connect] {msg}")

    if ok:
        pmf_ok, pmf_msg = check_pmf_active(interface)
        result["pmf_active"] = pmf_ok
        print(f"[PMF] {pmf_msg}")
        result["overall"] = "PASS" if pmf_ok else "FAIL"

    return result

if __name__ == "__main__":
    r = wpa3_test_flow("CorpWifi-WPA3", "testpassword123")
    print(f"\n[Result] {r}")
