The 'Why' — Conceptual Breakdown

DNS as a Connection Quality Signal

Slow DNS resolution is often the root cause of "the internet feels slow" complaints that are actually caused by 300ms DNS latency rather than low bandwidth. Enterprise deployments with split-horizon DNS (different DNS results inside vs. outside the corporate network) need automated verification to confirm clients get the right internal IPs when on the corporate WLAN.

dnspython gives you full DNS control from Python.
Unlike socket.getaddrinfo() (which uses the OS resolver with caching and no timing), dnspython sends raw DNS queries to specific servers and measures round-trip time precisely. This lets you compare your DHCP-assigned DNS server against public alternatives and detect captive portal DNS hijacking.

Canary Domain Testing

A canary domain is a well-known hostname that should always resolve correctly on a properly functioning network. For enterprise WLAN testing, you might use google.com (internet DNS), corp-intranet.example.com (internal DNS), and time.windows.com (NTP). If any of these fail to resolve, you have a specific, actionable DNS failure rather than a vague "network not working" report.

Block 1 — resolve() with Latency Measurement

dns.resolver.Resolver lets you configure which DNS server to query. Wrapping it with time.perf_counter() gives nanosecond-precision latency measurement — much more accurate than time.time().

Python Day23_dns_testing.py 
# =============================================================
# Day 23: DNS Resolution Testing
# pip install dnspython
# =============================================================

import dns.resolver
import dns.exception
import time
import statistics

def resolve(hostname, server=None, record_type="A", timeout=5):
    """
    Resolve a hostname using a specific DNS server.
    Returns: (answers: list, latency_ms: float, error: str or None)

    Args:
        hostname:    Domain name to resolve
        server:      DNS server IP (None = use system default)
        record_type: DNS record type ('A', 'AAAA', 'MX', 'TXT', etc.)
        timeout:     Query timeout in seconds
    """
    resolver = dns.resolver.Resolver()
    resolver.lifetime = timeout
    if server:
        resolver.nameservers = [server]   # Override the DNS server

    start = time.perf_counter()  # High-resolution timer
    try:
        answers = resolver.resolve(hostname, record_type)
        latency = (time.perf_counter() - start) * 1000  # Convert to ms
        ips = [str(r) for r in answers]
        return ips, round(latency, 2), None

    except dns.exception.Timeout:
        latency = (time.perf_counter() - start) * 1000
        return [], round(latency, 2), "TIMEOUT"

    except dns.resolver.NXDOMAIN:
        latency = (time.perf_counter() - start) * 1000
        return [], round(latency, 2), "NXDOMAIN (domain not found)"

    except Exception as e:
        latency = (time.perf_counter() - start) * 1000
        return [], round(latency, 2), str(e)

# Quick test
ips, latency, err = resolve("google.com")
print(f"google.com → {ips}  ({latency} ms)  err={err}")
Block 2 — benchmark_dns() — Four Servers in Parallel

Comparing DNS servers requires querying them under identical conditions. Using threading to send all queries simultaneously eliminates timing bias — results are comparable because they happen at the same moment.

Python 
import threading

DNS_SERVERS = {
    "Google":     "8.8.8.8",
    "Cloudflare": "1.1.1.1",
    "OpenDNS":    "208.67.222.222",
    "Quad9":      "9.9.9.9",
}

def benchmark_dns(hostname, repeat=5):
    """
    Benchmark multiple DNS servers by resolving the same hostname
    repeatedly and computing average latency.

    Args:
        hostname: Domain to use for the benchmark
        repeat:   Number of queries per server (more = more accurate average)
    """
    results = {}

    def query_server(name, server_ip):
        """Thread worker: query the server `repeat` times."""
        latencies = []
        for _ in range(repeat):
            _, latency_ms, err = resolve(hostname, server=server_ip)
            if not err:
                latencies.append(latency_ms)
            time.sleep(0.1)   # Brief pause between queries (polite behaviour)

        if latencies:
            results[name] = {
                "server":  server_ip,
                "avg_ms":  round(statistics.mean(latencies), 1),
                "min_ms":  round(min(latencies), 1),
                "max_ms":  round(max(latencies), 1),
                "success": len(latencies),
            }
        else:
            results[name] = {"server": server_ip, "avg_ms": None,
                             "success": 0, "error": "All queries failed"}

    # Launch all server queries in parallel threads
    threads = [threading.Thread(target=query_server, args=(name, ip))
               for name, ip in DNS_SERVERS.items()]
    for t in threads:
        t.start()
    for t in threads:
        t.join()   # Wait for all threads to complete

    # Print results sorted by average latency
    print(f"\n[DNS Benchmark] hostname='{hostname}'  ({repeat} queries each)")
    for name, r in sorted(results.items(), key=lambda x: x[1].get("avg_ms") or 9999):
        if r.get("avg_ms"):
            print(f"  {name:12s} {r['server']:15s}  avg={r['avg_ms']:6.1f}ms  "
                  f"min={r['min_ms']:5.1f}  max={r['max_ms']:5.1f}  ok={r['success']}/{repeat}")
        else:
            print(f"  {name:12s} {r['server']:15s}  FAILED")
    return results

benchmark_dns("google.com", repeat=3)
Block 3 — dns_health_check() with Canary Domains

A health check tests a set of canary domains that represent different DNS zones: public internet, corporate internal, and NTP. Any failure is a specific, actionable data point.

Python 
CANARY_DOMAINS = [
    "google.com",           # Public internet DNS
    "cloudflare.com",       # Public CDN
    "github.com",           # Developer tools
    "time.windows.com",     # NTP (should always resolve)
]

def dns_health_check(dns_server=None, canary_domains=None):
    """
    Check DNS health by resolving a set of canary domains.
    Returns: (healthy: bool, results: list of dicts)
    """
    domains = canary_domains or CANARY_DOMAINS
    results = []
    all_ok  = True

    print(f"\n[DNS Health Check] server={dns_server or 'system default'}")

    for domain in domains:
        ips, latency, err = resolve(domain, server=dns_server)
        ok = (err is None and len(ips) > 0)
        if not ok:
            all_ok = False

        results.append({
            "domain":  domain,
            "passed":  ok,
            "ips":     ips,
            "latency": latency,
            "error":   err
        })

        icon = "✓" if ok else "✗"
        print(f"  [{icon}] {domain:30s}  {latency:6.1f}ms  {ips[0] if ips else err}")

    print(f"\n  Overall: {'HEALTHY' if all_ok else 'DEGRADED'}")
    return all_ok, results

ok, report = dns_health_check()
