RSSI Monitoring —
Continuous Signal Strength Logging

A single RSSI reading tells you how strong the signal is right now. Continuous monitoring tells you when it drops, how long it stays low, and whether it's trending downward over time. Today you'll build a rolling-average RSSI monitor with configurable alerts, CSV logging, and a drop-detection function for roaming trigger analysis.

The 'Why' — Conceptual Breakdown

Why Continuous Monitoring Matters

RSSI is highly variable — it can swing ±10 dBm within a second due to multipath fading, interference, and transmit power fluctuations. A single snapshot is unreliable. A rolling average over 5-10 samples gives a stable, meaningful value for test assertions and alert thresholds.

The rolling average is your signal quality truth.
Enterprise WLAN testing uses a 5-sample rolling average to trigger roaming: when the average drops below -70 dBm, the client should roam to a stronger AP. Your automated test can verify this behavior by monitoring RSSI while physically moving the test device (or attenuating the signal programmatically).

RSSI Sources by Platform

On Linux: iw dev wlan0 link provides RSSI in the signal: -XX dBm line. On macOS: airport -I outputs agrCtlRSSI: -XX. On Windows: netsh wlan show interfaces gives Signal as a percentage. Day 10's parser already handles all three — today we call it repeatedly to build a time series.

import subprocess
import platform
import re
import time
import csv
import datetime
from collections import deque
from pathlib import Path

def get_rssi(interface="wlan0"):
    """
    Read the current RSSI from the connected AP.
    Returns RSSI in dBm (int) or None if not connected / not readable.
    """
    os_name = platform.system()

    if os_name == "Linux":
        result = subprocess.run(
            ["iw", "dev", interface, "link"],
            capture_output=True, text=True
        )
        m = re.search(r"signal:\s*(-\d+) dBm", result.stdout)
        return int(m.group(1)) if m else None

    elif os_name == "Darwin":
        airport = ("/System/Library/PrivateFrameworks/Apple80211.framework"
                   "/Versions/Current/Resources/airport")
        result = subprocess.run([airport, "-I"], capture_output=True, text=True)
        m = re.search(r"agrCtlRSSI:\s*(-\d+)", result.stdout)
        return int(m.group(1)) if m else None

    return None

rssi = get_rssi("wlan0")
print(f"[RSSI] Current: {rssi} dBm")
Block 2 — monitor_rssi() with Rolling Average and Alerts

collections.deque(maxlen=5) is a perfect rolling window — it automatically discards the oldest element when full, so the average is always computed over the last N readings without manual management.

Python 
def monitor_rssi(interface="wlan0", duration=60, interval=1.0,
                  alert_threshold=-75, window_size=5,
                  csv_path=None):
    """
    Continuously monitor RSSI for `duration` seconds.
    Maintains a rolling average over `window_size` samples.
    Alerts when rolling average drops below `alert_threshold`.
    Optionally writes all readings to a CSV file.

    Returns: list of (timestamp, rssi, rolling_avg) tuples
    """
    window   = deque(maxlen=window_size)
    readings = []
    csv_file = None
    csv_writer = None

    if csv_path:
        csv_file   = open(csv_path, "w", newline="")
        csv_writer = csv.writer(csv_file)
        csv_writer.writerow(["timestamp", "rssi_dbm", "rolling_avg", "alert"])

    try:
        end_time = time.time() + duration
        print(f"[Monitor] RSSI on {interface} for {duration}s  "
              f"(alert < {alert_threshold} dBm, window={window_size})")

        while time.time() < end_time:
            rssi = get_rssi(interface)
            ts   = datetime.datetime.now().strftime("%H:%M:%S.%f")[:-3]

            if rssi is not None:
                window.append(rssi)
                avg   = sum(window) / len(window)
                alert = avg < alert_threshold

                readings.append((ts, rssi, round(avg, 1)))

                if csv_writer:
                    csv_writer.writerow([ts, rssi, round(avg, 1), alert])

                bar_len = min(50, max(0, rssi + 100))  # -100→0, 0→100, clamp 0-50
                bar = "█" * (bar_len // 2) + "░" * (25 - bar_len // 2)
                alert_str = " ⚠ BELOW THRESHOLD" if alert else ""
                print(f"  {ts}  {rssi:4d} dBm  avg={avg:5.1f}  [{bar}]{alert_str}")

            time.sleep(interval)

    finally:
        if csv_file:
            csv_file.close()

    return readings
Block 3 — detect_drops() in Time Series

After monitoring, the time series can be analysed for signal drops — periods where RSSI stays below threshold for more than N consecutive seconds. These are candidate roaming events or coverage holes.

Python 
def detect_drops(readings, threshold=-75, min_duration_s=3):
    """
    Find periods in a RSSI time series where signal stayed below
    `threshold` for at least `min_duration_s` seconds.

    Args:
        readings: list of (timestamp, rssi, avg) tuples
        threshold: alert dBm threshold
        min_duration_s: minimum consecutive seconds below threshold

    Returns: list of drop events {start, end, duration_s, min_rssi}
    """
    drops = []
    in_drop   = False
    drop_start = None
    drop_rssis = []

    for ts, rssi, avg in readings:
        below = rssi < threshold

        if below and not in_drop:
            in_drop    = True
            drop_start = ts
            drop_rssis = [rssi]
        elif below and in_drop:
            drop_rssis.append(rssi)
        elif not below and in_drop:
            # Drop ended — check if it lasted long enough
            duration = len(drop_rssis)  # Each reading = 1 second
            if duration >= min_duration_s:
                drops.append({
                    "start":      drop_start,
                    "end":        ts,
                    "duration_s": duration,
                    "min_rssi":   min(drop_rssis),
                    "avg_rssi":   round(sum(drop_rssis)/len(drop_rssis), 1),
                })
            in_drop = False

    return drops

# Run for 30 seconds and analyse drops
csv_out  = Path("rssi_log.csv")
readings = monitor_rssi("wlan0", duration=30, alert_threshold=-75, csv_path=csv_out)
drops    = detect_drops(readings, threshold=-75, min_duration_s=3)
print(f"\n[Drops] {len(drops)} drop events found:")
for d in drops:
    print(f"  {d['start']} → {d['end']}  {d['duration_s']}s  min={d['min_rssi']} dBm")
