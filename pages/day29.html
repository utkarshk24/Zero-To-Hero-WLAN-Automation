Fixtures & conftest.py —
Shared Test Infrastructure

Fixtures are pytest's mechanism for setup and teardown — but they're far more powerful than unittest's setUp/tearDown. They compose, they scope to function, class, module, or session, and they clean up automatically via yield. Today you'll build the conftest.py that powers your entire WLAN test suite.

⏱~55 min
🐍Python 3.9+
📦pytest
🔧@pytest.fixture · yield · scope
🤔

The 'Why' — Conceptual Breakdown

The Problem Fixtures Solve

Without fixtures, every test function that needs scan data must call the scan function itself. In a 50-test suite, that means 50 network scan calls — each taking 3 seconds. Total: 150 seconds just for setup. With a session-scoped fixture, the scan runs once, and all 50 tests share the result. Total: 3 seconds.

Fixtures with yield are context managers for test setup.
Code before yield is setup (runs before the test). Code after yield is teardown (runs after the test, guaranteed). The scope parameter controls how often the fixture runs: function (every test), class, module, or session (once for the entire test run).

conftest.py: The Shared Fixture Hub

conftest.py is a special pytest file that pytest automatically discovers. Fixtures defined there are available to all tests in the same directory and all subdirectories — no imports needed. Put your AP inventory, scan data, interface management, and connection credentials here.

💻

Code Walkthrough — @pytest.fixture, scope, yield, and conftest.py

Create conftest.py in your test directory. Every test file in the same folder automatically has access to these fixtures.

Block 1 — Basic @pytest.fixture with scope
Python conftest.py 
# =============================================================
# conftest.py — Shared fixtures for the entire WLAN test suite
# pytest discovers this file automatically — no imports needed
# =============================================================

import pytest
import json
from pathlib import Path

# ── Block 1: Basic fixtures with scope ────────────────────────

@pytest.fixture(scope="session")
def ap_inventory():
    """
    Load the AP inventory JSON file once for the entire test session.
    scope="session" means this fixture runs ONCE per pytest invocation,
    not once per test — a 50-test suite loads the file exactly 1 time.
    """
    inventory_path = Path("ap_inventory.json")
    if not inventory_path.exists():
        pytest.skip("ap_inventory.json not found — skipping inventory tests")

    with open(inventory_path) as f:
        data = json.load(f)
    return data   # Returned value is injected as the fixture parameter

@pytest.fixture(scope="session")
def simulated_scan():
    """
    Provide simulated AP scan data for tests that don't need real hardware.
    Replace this with a real scan call when running on physical hardware.
    """
    return [
        {"ssid": "CorpWifi-5G",  "bssid": "AA:BB:CC:01:02:03",
         "rssi": -52, "channel": 36, "security": "WPA2"},
        {"ssid": "CorpWifi-2G",  "bssid": "AA:BB:CC:01:02:04",
         "rssi": -68, "channel": 6,  "security": "WPA2"},
        {"ssid": "GuestWifi",    "bssid": "AA:BB:CC:01:02:05",
         "rssi": -71, "channel": 11, "security": "WPA2"},
    ]

@pytest.fixture(scope="module")
def min_rssi_threshold():
    """Module-scoped: runs once per test module (file), not per test."""
    return -75
Block 2 — yield Fixtures for Setup and Teardown

yield inside a fixture splits it into setup (before yield) and teardown (after yield). The teardown code is guaranteed to run even if the test raises an exception — exactly like a finally block.

Python 
import subprocess
import os

# ── Block 2: yield fixtures for setup/teardown ─────────────────

@pytest.fixture(scope="function")
def temp_test_dir(tmp_path):
    """
    Create a temporary directory for test output files.
    tmp_path is a built-in pytest fixture that creates a unique temp dir.
    The directory is automatically cleaned up after each test.
    """
    test_dir = tmp_path / "wlan_test_output"
    test_dir.mkdir()
    yield test_dir
    # Teardown: pytest cleans up tmp_path automatically, but we can log here
    # print(f"\n[Fixture teardown] test dir was: {test_dir}")

@pytest.fixture(scope="session")
def monitor_interface():
    """
    Session-scoped fixture that enables monitor mode before all tests
    and restores managed mode after all tests complete.

    yield = the monitor interface name (used as 'iface' in tests)
    """
    iface = "wlan0"

    # Skip silently if not root (CI without hardware)
    if os.geteuid() != 0:
        pytest.skip("Monitor mode requires root — skipping hardware tests")

    # ── Setup ──────────────────────────────────────────────────
    print(f"\n[fixture] Enabling monitor mode on {iface}")
    subprocess.run(["ip", "link", "set", iface, "down"], check=True)
    subprocess.run(["iw", "dev", iface, "set", "type", "monitor"], check=True)
    subprocess.run(["ip", "link", "set", iface, "up"], check=True)

    yield iface   # ← Tests receive this value

    # ── Teardown (guaranteed to run) ──────────────────────────
    print(f"\n[fixture] Restoring {iface} to managed mode")
    subprocess.run(["ip", "link", "set", iface, "down"], check=True)
    subprocess.run(["iw", "dev", iface, "set", "type", "managed"], check=True)
    subprocess.run(["ip", "link", "set", iface, "up"], check=True)
Block 3 — Using Fixtures in Test Functions

Fixtures are injected by name — just include the fixture name as a parameter to your test function. pytest resolves it automatically.

Python test_with_fixtures.py 
# test_with_fixtures.py — uses fixtures from conftest.py

# No import of conftest needed — pytest injects fixtures by name

def test_inventory_has_aps(ap_inventory):
    """The AP inventory must not be empty."""
    aps = ap_inventory.get("access_points", [])
    assert len(aps) > 0, "Inventory is empty — check ap_inventory.json"

def test_scan_count_matches_inventory(simulated_scan, ap_inventory):
    """Number of discovered APs should match inventory count."""
    expected = len(ap_inventory.get("access_points", []))
    discovered = len(simulated_scan)
    assert discovered == expected, (
        f"Expected {expected} APs from inventory, scan found {discovered}"
    )

def test_rssi_above_threshold(simulated_scan, min_rssi_threshold):
    """Every AP must exceed the minimum RSSI threshold."""
    below = [ap for ap in simulated_scan if ap["rssi"] < min_rssi_threshold]
    assert len(below) == 0, (
        f"APs below {min_rssi_threshold} dBm: "
        + ", ".join(f"{a['ssid']} ({a['rssi']} dBm)" for a in below)
    )

def test_output_file_created(temp_test_dir):
    """Verify test output can be written to the temp directory."""
    output = temp_test_dir / "result.txt"
    output.write_text("PASS")
    assert output.exists()
    assert output.read_text() == "PASS"
