The 'Why' — Conceptual Breakdown

The Manual Tester's Decision Tree

Every time you review a Wi-Fi scan, your brain runs a decision tree without you realising it:

"If the signal is below -75 dBm, flag it as weak. If the security is Open, raise a critical alert. If the channel is 6 and there are 4 other APs on it, mark it as congested. Otherwise, mark it as healthy."

You do this for every single AP in the scan. If there are 30 APs in the office, you repeat that decision tree 30 times. Manually. Every test run.

Control flow is how you hand that decision tree to Python. You write the rules once — Python applies them to every AP in milliseconds, every time, without ever getting tired or making a typo.

Three Tools, Infinite Power

  • if / elif / else — make a decision based on a condition
  • for loop — repeat an action for every item in a collection
  • while loop — keep repeating until a condition is met (perfect for retry logic)

Combined, these three constructs let you automate any logic a human tester would apply — consistently, at machine speed.

Block 1 — if / elif / else: Signal Threshold Checker

The if statement evaluates a condition. If it's True, that block runs. elif (short for "else if") checks a second condition if the first was False. else is the catch-all that runs when nothing above matched.

# =============================================================

# --------------------------------------------------
# BLOCK 1: if / elif / else — Signal Threshold Checker
# --------------------------------------------------

def classify_signal(rssi: int) -> str:
    """
    Classify an RSSI value into a human-readable signal quality label.
    RSSI is always negative — closer to 0 means stronger signal.
    """
    if rssi >= -50:
        return "Excellent"       # Very close to the AP
    elif rssi >= -60:
        return "Good"            # Normal working range
    elif rssi >= -70:
        return "Fair"            # Acceptable but not ideal
    elif rssi >= -80:
        return "Weak"            # Connectivity issues likely
    else:
        return "Critical"        # Below -80 dBm: expect drops

# Test with a range of signal values
test_rssi_values = [-45, -58, -67, -76, -85]

print("=== Signal Quality Report ===")
for rssi in test_rssi_values:
    quality = classify_signal(rssi)
    print(f"  {rssi:>4} dBm  →  {quality}")
Block 2 — Nested if: Multi-Criteria AP Validation

Real WLAN tests rarely check just one thing. You can nest if statements inside each other — or combine conditions using and / or — to enforce multiple rules simultaneously.

Python 
# --------------------------------------------------
# BLOCK 2: Nested conditions — Multi-criteria AP check
# --------------------------------------------------

def validate_ap(ap: dict) -> tuple:
    """
    Run multiple checks on a single AP dictionary.
    Returns (passed: bool, reason: str).
    """
    # Check 1: Signal strength
    if ap["rssi"] < -80:
        return False, f"Signal too weak ({ap['rssi']} dBm)"

    # Check 2: Security must not be Open
    if ap["security"] == "Open":
        return False, "Open network — no encryption"

    # Check 3: Must be on a non-overlapping 2.4 GHz channel OR any 5/6 GHz channel
    bad_24ghz_channels = [2, 3, 4, 5, 7, 8, 9, 10]  # overlapping channels
    if ap["band"] == "2.4GHz" and ap["channel"] in bad_24ghz_channels:
        return False, f"Overlapping 2.4 GHz channel ({ap['channel']})"

    # All checks passed
    return True, "All checks passed"


# Simulate a scan with mixed results
scan_results = [
    {"ssid": "CorpNet_5G",   "rssi": -62, "band": "5GHz",   "channel": 36,  "security": "WPA3"},
    {"ssid": "CorpNet_2G",   "rssi": -71, "band": "2.4GHz", "channel": 1,   "security": "WPA2"},
    {"ssid": "Guest_Open",   "rssi": -65, "band": "2.4GHz", "channel": 6,   "security": "Open"},
    {"ssid": "Weak_AP",      "rssi": -85, "band": "5GHz",   "channel": 44,  "security": "WPA2"},
    {"ssid": "BadChannel_AP","rssi": -60, "band": "2.4GHz", "channel": 3,   "security": "WPA2"},
]

print("\n=== Multi-Criteria AP Validation ===")
for ap in scan_results:
    passed, reason = validate_ap(ap)
    status = "PASS ✓" if passed else "FAIL ✗"
    print(f"  [{status}]  {ap['ssid']:<18}  {reason}")
Block 3 — for Loop: Iterating Scan Results

A for loop runs a block of code once for every item in a list. This is how you process every AP in a scan, every SSID in a test plan, every channel in a frequency band — without copy-pasting code.

Python 
# --------------------------------------------------
# BLOCK 3: for loop — Channel Congestion Checker
# --------------------------------------------------

def check_channel_congestion(scan_results: list, threshold: int = 3) -> dict:
    """
    Count how many APs are on each channel.
    Flag channels where the count exceeds the threshold.

    Returns a dict: { channel_number: ap_count }
    """
    channel_counts = {}  # Empty dict — we'll populate it as we loop

    for ap in scan_results:
        ch = ap["channel"]

        # If this channel is already in the dict, increment the count
        # Otherwise, start the count at 1
        if ch in channel_counts:
            channel_counts[ch] += 1
        else:
            channel_counts[ch] = 1

    return channel_counts


# Use the same scan_results list from Block 2
channel_counts = check_channel_congestion(scan_results)

print("\n=== Channel Congestion Report ===")
for channel, count in sorted(channel_counts.items()):
    bar = "█" * count           # Visual bar chart — one block per AP
    flag = " ⚠ CONGESTED" if count >= 3 else ""
    print(f"  Ch {channel:>3}  {bar}  ({count} APs){flag}")
Block 4 — List Comprehension: Filter in One Line

Python has a shortcut for building a filtered list called a list comprehension. It replaces a full for loop + if + append() with a single, readable line. WLAN testers use this constantly to filter scan results by band, security, or signal.

Python 
# --------------------------------------------------
# BLOCK 4: List comprehension — Filter scan results
# --------------------------------------------------

# Standard for loop (verbose):
strong_aps_verbose = []
for ap in scan_results:
    if ap["rssi"] > -75:
        strong_aps_verbose.append(ap)

# Identical result, one line (list comprehension):
strong_aps = [ap for ap in scan_results if ap["rssi"] > -75]

# Filter: only 5 GHz APs
only_5ghz = [ap for ap in scan_results if ap["band"] == "5GHz"]

# Filter: only secured APs with good signal
secure_and_strong = [
    ap for ap in scan_results
    if ap["security"] != "Open" and ap["rssi"] > -75
]

# Extract just the SSIDs from filtered results (transform + filter)
secure_ssids = [ap["ssid"] for ap in scan_results if ap["security"] != "Open"]

print("\n=== Filtered Results ===")
print(f"  APs with RSSI > -75 dBm : {[a['ssid'] for a in strong_aps]}")
print(f"  5 GHz APs only           : {[a['ssid'] for a in only_5ghz]}")
print(f"  Secure + strong APs      : {[a['ssid'] for a in secure_and_strong]}")
print(f"  All secured SSIDs        : {secure_ssids}")
Block 5 — while Loop: Connection Retry Logic

A while loop keeps running as long as a condition is True. This is perfect for retry scenarios — keep trying to connect until it succeeds or you hit a maximum attempt limit. Every real WLAN test framework needs this.

Python 
# --------------------------------------------------
# BLOCK 5: while loop — Connection Retry Logic
# --------------------------------------------------
import time
import random  # We'll simulate random connection success/failure

def attempt_connection(ssid: str) -> bool:
    """Simulates a connection attempt. Returns True on success, False on failure."""
    # 60% chance of success — simulates a flaky AP for demonstration
    return random.random() < 0.6

def connect_with_retry(ssid: str, max_attempts: int = 5, delay_sec: float = 2.0) -> bool:
    """
    Try to connect to an SSID up to max_attempts times.
    Wait delay_sec seconds between each attempt.
    Returns True if connected, False if all attempts exhausted.
    """
    attempt = 1   # Counter starts at 1

    while attempt <= max_attempts:
        print(f"  [Attempt {attempt}/{max_attempts}] Connecting to '{ssid}'...")

        if attempt_connection(ssid):
            print(f"  ✓ Connected to '{ssid}' on attempt {attempt}")
            return True   # Success — exit the loop immediately

        print(f"  ✗ Attempt {attempt} failed.")

        if attempt < max_attempts:
            print(f"  Waiting {delay_sec}s before retry...")
            time.sleep(delay_sec)

        attempt += 1  # Increment counter — prevents infinite loop

    # If we reach here, all attempts failed
    print(f"  [FAIL] Could not connect to '{ssid}' after {max_attempts} attempts.")
    return False

print("\n=== Connection Retry Test ===")
result = connect_with_retry("CorpNet_5G", max_attempts=5, delay_sec=1)
print(f"  Final result: {'PASS' if result else 'FAIL'}")
Block 6 — Putting It All Together: Rogue AP Detector

Now we combine everything — loops, conditions, filtering — into a single function that scans a list of APs and automatically flags anything suspicious. This is a real-world pattern used in enterprise WLAN security testing.

Python 
# --------------------------------------------------
# BLOCK 6: Rogue AP Detector — all concepts combined
# --------------------------------------------------

# Approved APs from our network inventory (what SHOULD be there)
APPROVED_BSSIDS = {
    "AA:BB:CC:DD:EE:01",
    "AA:BB:CC:DD:EE:02",
    "AA:BB:CC:DD:EE:03",
}

# Extended scan with a rogue AP mixed in
full_scan = [
    {"ssid": "CorpNet_5G",  "bssid": "AA:BB:CC:DD:EE:01", "rssi": -62, "security": "WPA3"},
    {"ssid": "CorpNet_2G",  "bssid": "AA:BB:CC:DD:EE:02", "rssi": -70, "security": "WPA2"},
    {"ssid": "CorpNet_5G",  "bssid": "FF:EE:DD:CC:BB:AA", "rssi": -55, "security": "WPA3"},  # Rogue!
    {"ssid": "FreeWiFi",    "bssid": "11:22:33:44:55:66", "rssi": -60, "security": "Open"},   # Rogue!
    {"ssid": "CorpNet_IoT", "bssid": "AA:BB:CC:DD:EE:03", "rssi": -74, "security": "WPA2"},
]

def detect_rogues(scan: list, approved: set) -> list:
    """
    Compare every scanned AP against the approved BSSID inventory.
    Flag an AP as rogue if its BSSID is not in the approved set.
    """
    rogue_aps = []

    for ap in scan:
        is_approved = ap["bssid"] in approved
        is_open     = ap["security"] == "Open"

        if not is_approved or is_open:
            reason = []
            if not is_approved: reason.append("Unknown BSSID")
            if is_open:         reason.append("Open security")
            rogue_aps.append({**ap, "reasons": " + ".join(reason)})

    return rogue_aps


rogues = detect_rogues(full_scan, APPROVED_BSSIDS)

print("\n" + "=" * 55)
print("  ROGUE AP DETECTION REPORT")
print("=" * 55)
print(f"  Total APs scanned : {len(full_scan)}")
print(f"  Rogues detected   : {len(rogues)}")
print("-" * 55)

if rogues:
    for r in rogues:
        print(f"  ⚠  SSID   : {r['ssid']}")
        print(f"     BSSID  : {r['bssid']}")
        print(f"     RSSI   : {r['rssi']} dBm")
        print(f"     Reason : {r['reasons']}")
        print()
else:
    print("  ✓ No rogue APs detected.")

print("=" * 55)
