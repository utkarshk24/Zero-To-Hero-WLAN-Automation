The 'Why' — Conceptual Breakdown

pytest-html vs. Allure

pytest-html generates a flat list of passed and failed tests. Allure generates a full test management dashboard: tests grouped by feature (RSSI, Security, DNS), timeline charts showing when each test ran, severity classification (critical/major/minor), and step-by-step drill-down showing exactly what each test did and what it found at each step. For a WLAN certification report, Allure is the professional choice.

Allure uses a two-phase approach.
Phase 1: pytest generates raw JSON result files in an allure-results/ directory. Phase 2: the Allure CLI renders them into an interactive HTML report. This separation means you can regenerate the report from the same test data with different filters, groupings, or themes.

Block 1 — Feature, Story, and Severity Decorators
Python test_allure_demo.py 
# =============================================================
# Day 32: Allure Reports
# Run: pytest test_allure_demo.py --alluredir=allure-results
# View: allure serve allure-results
# =============================================================

import allure
import pytest

# ── Allure decorators ──────────────────────────────────────────

@allure.feature("RSSI Compliance")        # Groups tests into a Feature
@allure.story("Minimum RSSI Threshold")   # Sub-group (user story)
@allure.severity(allure.severity_level.CRITICAL)  # Critical = blocks deployment
def test_all_aps_above_minimum_rssi():
    """All APs must be above -75 dBm for production deployment."""
    scan = [
        {"ssid": "CorpWifi-5G", "rssi": -52},
        {"ssid": "CorpWifi-2G", "rssi": -68},
    ]
    failing = [ap for ap in scan if ap["rssi"] < -75]
    assert len(failing) == 0

@allure.feature("Security Compliance")
@allure.story("WPA2/3 Enforcement")
@allure.severity(allure.severity_level.CRITICAL)
def test_no_open_networks():
    """No AP may use Open (unencrypted) security in a production environment."""
    scan = [
        {"ssid": "CorpWifi-5G",  "security": "WPA2"},
        {"ssid": "GuestWifi",    "security": "WPA2"},
    ]
    open_nets = [ap for ap in scan if ap["security"] == "Open"]
    assert len(open_nets) == 0

@allure.feature("Channel Planning")
@allure.story("Non-Overlapping Channels")
@allure.severity(allure.severity_level.MAJOR)
def test_non_overlapping_channels():
    scan = [
        {"ssid": "CorpWifi-2G", "channel": 6},
        {"ssid": "GuestWifi",   "channel": 11},
    ]
    overlapping = [ap for ap in scan
                   if ap["channel"] <= 14
                   and ap["channel"] not in {1, 6, 11}]
    assert len(overlapping) == 0
Block 2 — @allure.step Context Manager

@allure.step marks a function as a named step in the test report. When the report is rendered, each step shows as a collapsible item with its own pass/fail status — giving you step-level granularity for debugging complex connection tests.

Python 
@allure.step("Perform Wi-Fi scan")
def do_scan():
    """Allure records this as a named step with pass/fail."""
    return [{"ssid": "CorpWifi-5G", "rssi": -52, "security": "WPA2"}]

@allure.step("Verify RSSI for {ssid}")
def verify_rssi(ssid, rssi, threshold=-75):
    """Step name includes the ssid parameter — shows in report."""
    assert rssi >= threshold, f"{ssid}: {rssi} dBm below {threshold} dBm"

@allure.step("Verify security for {ssid}")
def verify_security(ssid, security):
    assert security in {"WPA2", "WPA3"}, f"{ssid}: insecure ({security})"

@allure.feature("Connection Validation")
@allure.story("Full Validation Flow")
@allure.severity(allure.severity_level.CRITICAL)
def test_full_validation_with_steps():
    """Full test showing step-by-step execution in Allure report."""
    scan_results = do_scan()
    for ap in scan_results:
        verify_rssi(ap["ssid"], ap["rssi"])
        verify_security(ap["ssid"], ap["security"])
Block 3 — allure.attach() for Evidence

Attaching evidence makes reports self-contained audit documents. Attach RSSI readings as text, scan results as JSON, or log files as plain text — all viewable inline in the Allure report.

Python 
import json

@allure.feature("RSSI Compliance")
@allure.story("Evidence Attachment")
def test_with_evidence():
    """Demonstrate attaching evidence to an Allure test report."""
    scan_data = [
        {"ssid": "CorpWifi-5G",  "rssi": -52, "channel": 36},
        {"ssid": "CorpWifi-2G",  "rssi": -68, "channel": 6},
    ]

    # Attach the scan data as JSON evidence
    allure.attach(
        json.dumps(scan_data, indent=2),
        name="Scan Results",
        attachment_type=allure.attachment_type.JSON
    )

    # Attach a text summary
    summary = "\n".join(
        f"{ap['ssid']}: {ap['rssi']} dBm (Ch{ap['channel']})"
        for ap in scan_data
    )
    allure.attach(summary, name="RSSI Summary",
                  attachment_type=allure.attachment_type.TEXT)

    # Run the actual assertions
    for ap in scan_data:
        assert ap["rssi"] >= -75, f"{ap['ssid']}: {ap['rssi']} dBm"
Block 4 — Running and Serving the Allure Report
Bash 
# Run tests and generate Allure results (raw JSON)
pytest test_allure_demo.py --alluredir=allure-results -v

# Serve the report interactively (opens browser automatically)
allure serve allure-results

# OR: generate a static HTML report to share
allure generate allure-results -o allure-report --clean
# Open: allure-report/index.html
