The 'Why' — Conceptual Breakdown

When Script-Based Captures Beat Wireshark

Manual Wireshark captures require a human to start, wait, and stop. Automated captures run as part of your CI pipeline: start the capture when the test begins, run the connection test, stop the capture when it ends, and analyse the PCAP automatically. This gives you concrete packet-level evidence for every CI run — far more valuable than just pass/fail output.

tshark supports the same capture filters as Wireshark.
Use BPF capture filters to reduce file size: -f "wlan type mgt" captures only management frames. Use display filters with -Y to filter PCAP during analysis. The -T fields output format makes tshark output machine-parseable — no regex needed.

Block 1 — start_capture() with tshark subprocess
Python Day34_ota_capture.py 
# =============================================================
# Day 34: OTA Packet Capture Automation
# Requires: tshark + monitor-mode capable adapter + root
# =============================================================

import subprocess
import time
import signal
from pathlib import Path
from scapy.all import rdpcap, Dot11, RadioTap
from collections import Counter

def start_capture(interface, output_path, capture_filter=None):
    """
    Start a tshark capture as a background subprocess.
    Returns the Popen process object — call .terminate() to stop.

    Args:
        interface:      Monitor-mode interface (e.g. 'wlan0mon')
        output_path:    Path to write the PCAP file
        capture_filter: BPF capture filter string (None = capture all)
    """
    cmd = [
        "tshark",
        "-i", interface,
        "-w", str(output_path),  # Write PCAP to file
        "-q",                    # Quiet mode — suppress per-packet output
    ]
    if capture_filter:
        cmd.extend(["-f", capture_filter])

    print(f"[Capture] Starting: {' '.join(cmd)}")

    # Popen is non-blocking — tshark runs in background while our code continues
    proc = subprocess.Popen(
        cmd,
        stdout=subprocess.PIPE,
        stderr=subprocess.PIPE
    )
    return proc

def stop_capture(proc):
    """Stop a tshark capture process gracefully (SIGINT = Ctrl+C)."""
    if proc and proc.poll() is None:   # Still running
        proc.send_signal(signal.SIGINT)
        try:
            proc.wait(timeout=5)
        except subprocess.TimeoutExpired:
            proc.terminate()
    print("[Capture] Stopped")
Block 2 — capture_context() Context Manager

The context manager pattern ensures tshark is always stopped even if the test code inside raises an exception. The captured file is always written cleanly.

Python 
import contextlib

@contextlib.contextmanager
def capture_context(interface, output_path, capture_filter=None):
    """
    Context manager for OTA packet captures.

    Usage:
        with capture_context("wlan0mon", "test.pcap") as pcap_path:
            # Run your test here
            time.sleep(10)
        # tshark is stopped, PCAP is complete
        analyse_pcap(pcap_path)
    """
    proc = start_capture(interface, output_path, capture_filter)
    time.sleep(0.5)   # Give tshark time to initialise

    try:
        yield Path(output_path)   # The test receives the PCAP path

    finally:
        stop_capture(proc)
        time.sleep(0.5)   # Allow file write to flush

Block 3 — analyse_pcap() with Scapy

After capturing, analyse the PCAP using Scapy's rdpcap(). Count frame types, extract unique BSSIDs, and measure RSSI distribution.

Python 
FRAME_TYPE_NAMES = {
    (0, 8): "Beacon", (0, 4): "Probe Req", (0, 5): "Probe Resp",
    (0, 0): "Assoc Req", (0, 1): "Assoc Resp",
    (0, 11): "Auth", (0, 12): "Deauth",
    (2, 0): "Data", (2, 8): "QoS Data",
}

def analyse_pcap(pcap_path):
    """
    Analyse a PCAP file and print statistics.
    Uses Scapy to read frame types, BSSIDs, and RSSI values.
    """
    if not Path(pcap_path).exists():
        print(f"[Analyse] PCAP not found: {pcap_path}")
        return {}

    packets = rdpcap(str(pcap_path))
    print(f"\n[Analyse] {pcap_path}: {len(packets)} frames")

    frame_counts = Counter()
    bssids       = set()
    rssi_values  = []

    for pkt in packets:
        if pkt.haslayer(Dot11):
            t  = pkt[Dot11].type
            st = pkt[Dot11].subtype
            name = FRAME_TYPE_NAMES.get((t, st), f"T{t}/S{st}")
            frame_counts[name] += 1

            if pkt[Dot11].addr3:
                bssids.add(pkt[Dot11].addr3)

        if pkt.haslayer(RadioTap):
            rssi = getattr(pkt[RadioTap], "dBm_AntSignal", None)
            if rssi:
                rssi_values.append(rssi)

    print(f"\n[Frame Types]")
    for frame_type, count in frame_counts.most_common():
        bar = "█" * min(40, count // 5)
        print(f"  {frame_type:15s} {count:5d}  {bar}")

    if rssi_values:
        print(f"\n[RSSI] min={min(rssi_values)} max={max(rssi_values)} "
              f"avg={sum(rssi_values)/len(rssi_values):.1f} dBm")

    print(f"[BSSIDs] {len(bssids)} unique: {list(bssids)[:3]}...")
    return {"frame_counts": dict(frame_counts), "bssids": len(bssids)}
