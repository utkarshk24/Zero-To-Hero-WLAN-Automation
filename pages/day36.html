The 'Why' — Conceptual Breakdown

Manual Roaming vs. Automated Roaming Tests

Manual roaming testing: you walk your device from one AP to another, watch the connection drop briefly, wait for reassociation, then record a vague note like "roaming worked" in your lab notebook. You do this 5 times because the first 3 times your notes are incomplete.

Automated roaming testing: your script triggers a roam, measures latency with millisecond precision, captures the frame exchange with Wireshark, logs the BSSID before and after, and reports: "Roamed from AP-01 to AP-02 in 45 ms, zero packet loss, 802.11r pre-auth confirmed."

802.11r/k/v are the roaming standards enterprise expects.
802.11r (Fast Roaming) pre-authenticates so roaming takes <50 ms. 802.11k (Neighbor Reports) gives clients a list of APs to prefer. 802.11v (BSS Transition Management) lets the AP suggest or force a roam. If your APs don't support these, your tests will show it.

Block 1 — Detecting Roaming Capabilities (802.11r/k/v)
Python Day36_roaming_test.py 
import subprocess, re, time

def check_roaming_capabilities(interface="wlan0"):
    """Check which 802.11r/k/v capabilities are active on the current connection."""
    result = subprocess.run(
        ["iw", "dev", interface, "link"],
        capture_output=True, text=True
    )
    output = result.stdout.lower()
    caps = {
        "802.11r_ft":  "ft" in output or "fast-transition" in output,
        "802.11k_rrm": "rrm" in output or "radio-resource" in output,
        "802.11v_btm": "bss-trans" in output or "btm" in output,
    }
    print(f"\n[Roaming Capabilities for {interface}]")
    for cap, supported in caps.items():
        status = "✓ Supported" if supported else "✗ Not detected"
        print(f"  {cap:15s}: {status}")
    return caps


def get_current_bssid(interface="wlan0"):
    """Return the BSSID of the currently associated AP."""
    r = subprocess.run(["iw", "dev", interface, "link"], capture_output=True, text=True)
    m = re.search(r"Connected to ([0-9a-f:]{17})", r.stdout, re.IGNORECASE)
    return m.group(1).upper() if m else None
Block 2 — Measuring Roaming Latency

Measure the time from the original BSSID to the target BSSID. Roaming latency is the time a device takes to disconnect from one AP and connect to another. Enterprise targets: <50 ms (with 802.11r), conservative: <150 ms.

Python Day36_roaming_test.py 
def measure_roaming_latency(interface="wlan0", target_bssid=None, timeout=10):
    """
    Measure time from current BSSID → new BSSID (in milliseconds).
    Returns (latency_ms, error_string) tuple.
    """
    original_bssid = get_current_bssid(interface)
    if not original_bssid:
        return None, "Not connected"

    print(f"\n[Roaming Monitor] Tracking roam from {original_bssid}...")
    start = time.perf_counter()
    deadline = start + timeout

    while time.perf_counter() < deadline:
        current = get_current_bssid(interface)
        if current and current != original_bssid:
            if target_bssid is None or current == target_bssid.upper():
                latency = (time.perf_counter() - start) * 1000
                print(f"  Roamed to {current} in {latency:.1f} ms")
                return round(latency, 1), None
        time.sleep(0.01)   # 10 ms polling interval

    return None, f"No roam detected within {timeout}s"


def trigger_roam_via_btm(interface="wlan0", target_bssid=None):
    """Send BSS Transition Management request to trigger a roam via wpa_cli."""
    cmd = ["wpa_cli", "-i", interface, "roam"]
    if target_bssid:
        cmd.append(target_bssid)
    result = subprocess.run(cmd, capture_output=True, text=True)
    print(f"[Roam Trigger] Command: {' '.join(cmd)}")
    print(f"[Roam Trigger] Response: {result.stdout.strip()}")
Block 3 — PyTest Integration with Allure

Wire roaming tests into your pytest suite. Use fixtures to capture pre/post BSSID state, measure latency, and assert SLA compliance.

Python Day36_roaming_test.py 
import pytest, allure

ROAMING_LATENCY_LIMIT_MS = 150   # Wi-Fi 6 target: <50 ms; conservative: <150 ms

@allure.feature("Roaming")
@allure.severity(allure.severity_level.CRITICAL)
@pytest.mark.live
def test_roaming_latency():
    """Verify roaming completes within the SLA."""
    check_roaming_capabilities("wlan0")

    before = get_current_bssid("wlan0")
    allure.attach(f"Source BSSID: {before}", name="Pre-roam state")
    print(f"\n[Test] Starting roam from {before}...")

    trigger_roam_via_btm("wlan0")
    latency, err = measure_roaming_latency("wlan0", timeout=5)

    after = get_current_bssid("wlan0")
    allure.attach(f"Target BSSID: {after}\nLatency: {latency} ms", name="Post-roam state")

    assert err is None, f"Roaming failed: {err}"
    assert latency <= ROAMING_LATENCY_LIMIT_MS, \
        f"Roaming too slow: {latency} ms > {ROAMING_LATENCY_LIMIT_MS} ms"
    assert before != after, "BSSID did not change — no roaming occurred"
    print(f"✓ Test passed. Roaming latency: {latency} ms")
