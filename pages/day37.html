Introduction to GitHub Actions CI/CD

Your test suite runs manually today. Tomorrow it runs automatically on every commit. Today you'll write GitHub Actions workflow files that install your dependencies, run PyTest, and publish reports — so every push to your repo is automatically tested.

GitHub Actions Workflow YAML Jobs & Steps Artifacts Triggers

1 — Your First Workflow File

bash 

# .github/workflows/test.yml

name: WLAN Automation Tests

on:
  push:
    branches: [ main, develop ]
  pull_request:
    branches: [ main ]

jobs:
  test:
    runs-on: ubuntu-latest

    steps:
      - name: Checkout repository
        uses: actions/checkout@v4

      - name: Set up Python
        uses: actions/setup-python@v5
        with:
          python-version: "3.12"

      - name: Install dependencies
        run: |
          python -m pip install --upgrade pip
          pip install -r requirements.txt

      - name: Run tests (unit tests only — no hardware needed)
        run: pytest -m "not live" -v --html=reports/report.html --self-contained-html

      - name: Upload HTML report
        uses: actions/upload-artifact@v4
        if: always()   # upload even if tests fail
        with:
          name: test-report-${{ github.run_number }}
          path: reports/report.html

2 — Workflow with Matrix (Multiple Python Versions)

bash 

jobs:
  test:
    runs-on: ubuntu-latest
    strategy:
      matrix:
        python-version: ["3.10", "3.11", "3.12"]

    steps:
      - uses: actions/checkout@v4

      - name: Set up Python ${{ matrix.python-version }}
        uses: actions/setup-python@v5
        with:
          python-version: ${{ matrix.python-version }}

      - name: Install and test
        run: |
          pip install -r requirements.txt
          pytest -m "not live" -v

4 — Useful GitHub Actions Patterns

bash 

# Run only on specific file changes (skip CI for docs changes)
on:
  push:
    paths:
      - 'src/**'
      - 'tests/**'
      - 'requirements.txt'

# Pass secrets as environment variables (never hardcode credentials)
      - name: Run with credentials
        env:
          WIFI_PASSWORD: ${{ secrets.CORP_WIFI_PASSWORD }}
          AP_INVENTORY:  ${{ secrets.AP_INVENTORY_PATH }}
        run: pytest

# Cache pip dependencies (faster CI runs)
      - name: Cache pip
        uses: actions/cache@v4
        with:
          path: ~/.cache/pip
          key: ${{ runner.os }}-pip-${{ hashFiles('requirements.txt') }}
