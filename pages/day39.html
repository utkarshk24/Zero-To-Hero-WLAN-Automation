Secrets & Environment Configuration

Wi-Fi passwords, AP credentials, and SMTP keys don't belong in code. Today you'll master the right way to manage secrets in Python automation — python-dotenv locally, GitHub Secrets in CI, and runtime validation so tests fail fast with a clear message if config is missing.

1 — Using python-dotenv for Local Development

python 

# pip install python-dotenv

2 — .gitignore: Never Commit Secrets

bash 

# .gitignore — add these BEFORE your first commit
.env
.env.*
*.env
secrets/
credentials.json
ap_passwords.yaml

# Check if you've accidentally staged a secret file:
git status --short | grep "\.env"

# If .env was already committed — remove it:
git rm --cached .env
echo ".env" >> .gitignore
git commit -m "Remove .env from tracking"

3 — GitHub Secrets for CI

bash 

# In GitHub repo: Settings → Secrets and variables → Actions
# Add secrets: WIFI_SSID, WIFI_PASSWORD, MIN_RSSI

# Use them in workflow:
# .github/workflows/test.yml
jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - name: Run WLAN tests
        env:
          WIFI_SSID:     ${{ secrets.WIFI_SSID }}
          WIFI_PASSWORD: ${{ secrets.WIFI_PASSWORD }}
          MIN_RSSI:      ${{ secrets.MIN_RSSI }}
        run: pytest tests/ -m "not live" -v

4 — Config Validation at Test Startup

python 

# config.py — centralised config loader with validation

import os
from dotenv import load_dotenv

load_dotenv()

REQUIRED_VARS = ["WIFI_SSID", "WIFI_PASSWORD"]
OPTIONAL_VARS = {
    "MIN_RSSI":     "-70",
    "TEST_ENV":     "local",
    "AP_INTERFACE": "wlan0",
    "IPERF_SERVER": "192.168.1.100",
}

def load_config():
    """Load and validate all required environment variables."""
    missing = [v for v in REQUIRED_VARS if not os.environ.get(v)]
    if missing:
        raise EnvironmentError(
            f"Missing required environment variables: {missing}\n"
            f"Copy .env.example to .env and fill in the values."
        )
    config = {v: os.environ[v] for v in REQUIRED_VARS}
    config.update({k: os.environ.get(k, default) for k, default in OPTIONAL_VARS.items()})
    config["MIN_RSSI"] = int(config["MIN_RSSI"])
    return config
