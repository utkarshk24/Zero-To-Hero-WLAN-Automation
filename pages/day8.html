The 'Why' — What This Capstone Builds

Bringing It All Together

In Days 1–7 you've built every individual component: a Python environment, reusable functions, file I/O, JSON parsing, and YAML config loading. A capstone project is where you wire all those components into a single cohesive tool that solves a real problem.

The problem we're solving: a WLAN test engineer needs to verify that every AP in a deployment matches its documented configuration — correct SSID, correct channel, correct security, and RSSI above the site threshold. Doing this manually takes 30 minutes per floor. With this tool: one command, 5 seconds.

This is a production-grade tool, not a demo.

Code Walkthrough — The Complete Validation Tool

Create Day08_capstone.py. This is the largest script so far — read every comment carefully. Each function is small and testable in isolation.

Block 1 — Imports and Config Loaders

The script loads two separate config sources: structured AP data from JSON and threshold parameters from YAML. Keeping data and config separate is a core software engineering principle — it lets you update thresholds without touching the AP inventory and vice versa.

Python Day08_capstone.py 
# =============================================================
# Day 8 Capstone: WLAN Config Parser & Validator
# Combines: JSON inventory + YAML thresholds + simulated scan
#           + validation engine + CSV report + summary.txt
# =============================================================

import json, yaml, csv, sys
import datetime
from pathlib import Path

def load_inventory(path):
    """Load AP inventory from a JSON file."""
    with open(path) as f:
        return json.load(f)

def load_config(path):
    """Load test thresholds from a YAML file."""
    with open(path) as f:
        return yaml.safe_load(f)

def get_simulated_scan():
    """
    Return a simulated Wi-Fi scan result.
    In Day 9+ this will be replaced with a real subprocess call.
    """
    return [
        {"ssid": "CorpWifi-5G", "bssid": "AA:BB:CC:01:02:03",
         "rssi": -55, "channel": 36, "security": "WPA2"},
        {"ssid": "CorpWifi-2G", "bssid": "AA:BB:CC:01:02:04",
         "rssi": -76, "channel": 6,  "security": "WPA2"},
        {"ssid": "GuestWifi",   "bssid": "AA:BB:CC:01:02:05",
         "rssi": -68, "channel": 11, "security": "Open"},
    ]
Block 2 — Multi-Check Validation Engine

The validation engine checks each AP against three independent criteria. Each check returns a reason string if it fails, or None if it passes. Collecting all failures before returning lets you give the engineer a complete picture — not just the first failure.

Python 
def validate_ap(expected, actual, thresholds):
    """
    Validate one AP against its expected config and site thresholds.
    Returns: list of failure strings (empty list = PASS).
    """
    failures = []
    min_rssi       = thresholds["min_rssi_dbm"]
    required_sec   = thresholds["required_security"]

    # Check 1: RSSI threshold
    if actual["rssi"] < min_rssi:
        failures.append(
            f"RSSI {actual['rssi']} dBm below threshold {min_rssi} dBm"
        )

    # Check 2: Security type must be in the approved list
    if actual["security"] not in required_sec:
        failures.append(
            f"Security '{actual['security']}' not in approved {required_sec}"
        )

    # Check 3: Channel must match the declared channel
    if actual["channel"] != expected["channel"]:
        failures.append(
            f"Channel {actual['channel']} does not match expected {expected['channel']}"
        )

    return failures   # Empty = PASS

def run_validation(inventory, live_scan, thresholds):
    """
    Run full validation for every expected AP.
    Returns: list of result dicts ready for CSV output.
    """
    scan_lookup = {ap["ssid"]: ap for ap in live_scan}
    results = []

    for expected in inventory["access_points"]:
        ssid   = expected["ssid"]
        actual = scan_lookup.get(ssid)
        ts     = datetime.datetime.now().strftime("%Y-%m-%d %H:%M:%S")

        if actual is None:
            results.append({"timestamp": ts, "ssid": ssid,
                             "result": "FAIL", "reason": "AP not found in scan",
                             "rssi": "N/A", "security": "N/A", "channel": "N/A"})
            continue

        failures = validate_ap(expected, actual, thresholds)
        status   = "PASS" if not failures else "FAIL"
        reason   = "; ".join(failures) if failures else "All checks passed"

        results.append({"timestamp": ts, "ssid": ssid,
                         "result": status, "reason": reason,
                         "rssi": actual["rssi"], "security": actual["security"],
                         "channel": actual["channel"]})
    return results
Block 3 — CSV Report Writer

The CSV report is the machine-readable output — perfect for feeding into dashboards, CI artefacts, or email attachments.

Python 
def write_csv_report(results, out_dir):
    """Write validation results to a timestamped CSV file."""
    ts_file = datetime.datetime.now().strftime("%Y%m%d_%H%M%S")
    path = out_dir / f"report_{ts_file}.csv"

    fields = ["timestamp", "ssid", "result", "reason", "rssi", "security", "channel"]
    with open(path, "w", newline="") as f:
        writer = csv.DictWriter(f, fieldnames=fields)
        writer.writeheader()
        writer.writerows(results)

    print(f"[CSV] Report written: {path}")
    return path
Block 4 — summary.txt Writer and Main Entry Point

The summary file is the human-readable output — what an engineer reads first. The main function orchestrates all previous components and exits with code 0 (success) or 1 (failures found), making the tool CI-friendly.

Python 
def write_summary(results, out_dir):
    """Write human-readable summary.txt."""
    passed = [r for r in results if r["result"] == "PASS"]
    failed = [r for r in results if r["result"] == "FAIL"]
    path = out_dir / "summary.txt"

    with open(path, "w") as f:
        f.write(f"WLAN Validation Summary\n")
        f.write(f"Run at: {datetime.datetime.now()}\n")
        f.write(f"{'='*50}\n")
        f.write(f"Total APs : {len(results)}\n")
        f.write(f"PASSED    : {len(passed)}\n")
        f.write(f"FAILED    : {len(failed)}\n\n")
        if failed:
            f.write("FAILURES:\n")
            for r in failed:
                f.write(f"  ✗ {r['ssid']} — {r['reason']}\n")
    print(f"[TXT] Summary written: {path}")

def main():
    out_dir = Path("reports")
    out_dir.mkdir(exist_ok=True)   # Create reports/ folder if it doesn't exist

    # Load configs (files created by Day 7 script)
    inventory  = load_inventory(Path("ap_inventory.json"))
    config     = load_config(Path("test_config.yaml"))
    thresholds = config["thresholds"]
    live_scan  = get_simulated_scan()

    # Run validation
    results = run_validation(inventory, live_scan, thresholds)

    # Write outputs
    write_csv_report(results, out_dir)
    write_summary(results, out_dir)

    # Print console summary
    failed = [r for r in results if r["result"] == "FAIL"]
    print(f"\n{'='*40}")
    print(f"RESULT: {len(results) - len(failed)}/{len(results)} APs PASSED")
    if failed:
        print(f"FAILED APs:")
        for r in failed:
            print(f"  ✗ {r['ssid']}: {r['reason']}")

    sys.exit(1 if failed else 0)   # CI-friendly exit code

if __name__ == "__main__":
    main()
